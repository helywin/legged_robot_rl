## Python 项目环境

除非某条记录另外标明工作目录，仓库内命令均从本仓库根目录执行。Markdown 文件链接相对所在文档；感知四足仓库按与本仓库同级存放约定链接。`~` 表示运行相应 Linux 环境时的用户主目录。

纯 Python 课程使用根目录的 `pyproject.toml` 管理项目元数据和依赖，并统一在 `.venv` 中运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --editable '.[dev]'
.venv/bin/python -m unittest discover -s tests -v
```

从第 040 课开始使用 PyTorch。当前只需要 CPU 计算，先完成上面的基础安装，再执行：

```bash
.venv/bin/python -m pip install \
  --index-url https://download.pytorch.org/whl/cpu \
  'torch>=2.13,<3'
```

`.venv/` 已加入 `.gitignore`，不提交到仓库。后续课程、示例和测试不使用裸 `python` 或系统 Python；新增第三方依赖时先写入 `pyproject.toml`，再安装到 `.venv`。

## 从已有基础继续的顺序

本节只保留路线摘要；教学内容、阶段过关标准和当前进度以 [[教学计划]] 为准。

已有 Q-learning、环境接口、神经网络与 DQN 内容按需回看，不重上一整套基础。

1. **200—206：小型 PPO。** 从动作概率、回报和价值基准逐步走到裁剪更新，亲手完成训练与评测。
2. **207—210：连续动作与并行采样。** 完成连续控制小任务，再阅读目标算法。
3. **500—507：Go2 身体与运动。** 观察 GUI，理解 PD、坐标、平地训练和地形实验。
4. **508—517：读懂并运行 learn 主链路。** 连接高程、历史、奖励与状态估计，完成受控训练、评测和续训。
5. **518—524：状态估计与扩展网络。** 学习归一化、HIM、辅助目标、空间编码及推理边界。
6. **525—531：报告中的激光感知。** 实现点云编码、运动补偿、本体融合、几何监督及消融。
7. **532—536：跨仿真与部署。** 在 Gazebo 评测，条件具备后做真机验证，形成自己的报告；537 为可选管理平台。

保留已有课号 500，109—119 暂不使用。每个完整任务可以分多次会话完成，只学习当前单元；先讲机制，再自己实现，最后用真实结果判断。始终沿用同一个闭环：

```text
观察 -> 神经网络策略 -> 动作
 ^                       |
 |------ 环境与奖励 ------|
```

真实机器人部署不属于初期实验。进入该阶段前，还需要完整机器人模型、关节限位、惯量、碰撞体、执行器参数、安全限幅和急停方案。
