# DQN 怎样替代 Q 表

## 本课目标

只理解一个变化：**DQN 使用神经网络估计每个动作的 Q 值，不再为每个观察保存一行 Q 表。**

```text
当前观察 → 神经网络 → 每个可选动作的 Q 值 → 选择动作
```

观察、动作、奖励和 Q-learning 想估计“这个动作将来有多好”的目标没有因此消失。

## Q 表与 DQN

| 对比 | Q 表 | DQN |
| --- | --- | --- |
| 输入 | 离散观察的编号 | 当前观察中的多个数或画面 |
| 输出 | 查到这一行各动作的 Q 值 | 网络估计各动作的 Q 值 |
| 保存方式 | 每种观察单独一行 | 共享一组网络参数 |
| 新的相似观察 | 没有对应行就没有经验 | 可能得到与相似观察接近的输出 |

最后一项能力叫**泛化**：在相似输入上复用已经学到的规律。

## 学习者回答与纠正

1. 学习者回答“输入观察，输出 Q 值”。补充为：输出是**每个可选动作各自的 Q 值**。
2. 学习者回答“神经网络可以对输入做估计”。进一步确认：相似输入经过同一套网络计算，可能得到相似输出，因此能共享经验。
3. 学习者正确指出：DQN 只取代了 Q 值的保存和估计方式，没有取代观察、动作和奖励闭环。
4. 在位置 100 与位置 101 都遇到坑的场景中，学习者能区分：Q 表分别保存两个观察，神经网络可能让相似输入产生相似输出。
