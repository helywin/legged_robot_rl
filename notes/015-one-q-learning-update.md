# 拼成一次完整的 Q-learning 更新

前两课分别学习了：

1. 用学习率让旧 Q 值朝新结果移动；
2. 用当前奖励和下一位置最佳 Q 值计算目标值。

现在把它们按顺序拼起来，但仍然只处理一次交互、只修改 Q 表中的一个格子。

## 第一步：计算目标值

假设这次经历是：

```text
位置 2 --right / reward=-0.01--> 位置 3
```

已知：

- `Q(位置2, right)` 的旧值是 `0.30`；
- 位置 3 的最高 Q 值是 `0.80`；
- 折扣因子是 `0.90`；
- 学习率是 `0.20`。

先计算这次应该参考的目标：

```text
目标值 = 当前奖励 + 折扣因子 × 下一位置最高 Q 值
       = -0.01 + 0.90 × 0.80
       = 0.71
```

## 第二步：让旧 Q 值朝目标移动

旧 Q 值是 `0.30`，目标值是 `0.71`：

```text
差距 = 0.71 - 0.30 = 0.41
修正量 = 0.20 × 0.41 = 0.082
新 Q 值 = 0.30 + 0.082 = 0.382
```

因此本次只执行：

```text
Q(位置2, right): 0.30 → 0.382
```

位置 3 的一行只是被读取，用来找最高值 `0.80`，并没有在这次计算中被修改。

## 两步不要混在一起

```text
奖励和未来价值 ──计算──> 目标值 0.71
旧 Q 值和目标值 ──按学习率修正──> 新 Q 值 0.382
```

> [!important]
> 目标值是 `0.71`，最终写回 Q 表的新值是 `0.382`。两者不同，是因为学习率只有 `0.20`。

## 到达终点时

如果动作执行后已经到达终点，未来价值为零：

```text
目标值 = 当前终点奖励
```

然后仍然使用学习率，让旧 Q 值朝这个终点奖励移动。

## Python 演示

```bash
.venv/bin/python -m examples.q_learning_single_update
```

这个程序只演示一次更新。下一阶段才会把动作选择、环境交互和 Q 值更新放进循环，让整张 Q 表通过多轮练习逐渐变化。

## 思考题

1. 上面例子中的目标值是多少？
2. 旧 Q 值是 `0.30`、目标值是 `0.71`，两者差距是多少？
3. 学习率为 `0.20` 时，修正量和最终新 Q 值分别是多少？
4. 本次更新读取了 Q 表的哪些部分，最终只修改了哪个格子？
