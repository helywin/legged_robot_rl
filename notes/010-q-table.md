# Q 表如何保存经验

## 为什么需要一张表

前面的 `right` 和随机策略不会根据结果改变。要让策略真正学习，它需要保存过去尝试得到的经验。

走格子环境很小，可以用一张 **Q 表**保存经验：

| 当前位置（观察） | `left` 的分数 | `right` 的分数 |
| --- | ---: | ---: |
| 0 | 0.00 | 0.00 |
| 1 | 0.00 | 0.00 |
| 2 | 0.00 | 0.00 |
| 3 | 0.00 | 0.00 |

每一行对应一个观察，每一列对应一个动作。格子里的 Q 分数表示：

> 在这个位置选择这个动作，从当前和后续结果来看，大概有多值得。

它不是环境刚刚给出的单次奖励，而是策略经过多次经验后保存的判断。

## 策略怎样使用 Q 表

假设学习后位置 `2` 的一行变成：

| 当前位置 | `left` | `right` |
| --- | ---: | ---: |
| 2 | 0.30 | 0.80 |

策略看到当前位置为 `2` 时，会更倾向选择分数较高的 `right`。

## 为什么一开始全是零

训练开始前，策略还不知道哪个动作更好，所以先把所有分数设为 `0`。它需要尝试不同动作，收到环境奖励，再逐渐修改表中的数字。

本课先理解“表中保存什么”。下一步才学习数字如何更新。

## 思考题

1. 位置 `2` 时，`left=0.30`、`right=0.80`，策略更倾向选择哪个动作？
2. Q 分数与环境在某一个 step 给出的即时奖励，是完全相同的东西吗？为什么？
3. 所有 Q 分数一开始都是 `0`，为什么不能永远只选表中当前看起来最好的一个动作，而需要尝试不同动作？
4. 训练后 Q 表里的数字发生变化，改变的是环境规则，还是策略保存的经验？

## 答题记录与辨析

- 第 1 题：正确，选择 Q 分数较高的 `right`。
- 第 2 题：正确。即时奖励来自当前一次交互，Q 分数是多次尝试后保存的经验判断。
- 第 3 题：需要修正。尝试不同动作的首要目的不是提高泛化性，而是发现尚未尝试过的动作是否更好。
- 第 4 题：正确，改变的是策略保存的经验，环境规则没有因此改变。

## 探索

主动尝试还不确定的动作，叫作**探索**。

假设位置 `0` 的两个 Q 分数一开始都是 `0`。如果平分时程序永远选择 `left`：

```text
位置 0 → left → 仍在位置 0 → 得到 -0.01
```

它可能一直重复这个动作，从未发现 `right` 可以靠近目标。训练时偶尔随机尝试其他动作，才有机会获得新经验并修改 Q 表。

## 追问

1. 所有 Q 分数都是 `0`，平分时永远选 `left`，小人可能会出现什么行为？它能发现目标在右边吗？
2. 如果训练时偶尔随机选择动作，这些随机尝试的主要作用是什么？

## 追问回答

- 如果平分时永远选择 `left`，小人会一直撞左边界，不能发现右边目标。
- 随机尝试的主要作用是发现尚未尝试的动作是否更好。
