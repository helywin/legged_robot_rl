# 终点价值怎样传到更早的位置

## 本课问题

位置 3 向右一步就能获得终点奖励，因此它很容易学会 `right` 很有价值。但位置 0 距离终点还有四步，它怎样知道向右值得？

答案是：**更晚位置已经学到的 Q 值，会在后续 episode 中成为更早位置的未来价值。**

这里称为“价值传播”。不要把它与以后神经网络中的“反向传播”混淆。

## 受控演示条件

为了只观察传播过程，固定以下条件：

| 条件 | 设置 |
| --- | --- |
| 动作 | 每个位置都固定选择 `right` |
| 探索 | 不使用 |
| 学习率 | `1.0`，让变化清楚可见 |
| 折扣因子 | `0.9` |
| 每步奖励 | 未到终点 `-0.01`，到终点 `+1.00` |
| 训练轮数 | `4` 个 episode |

这不是为了寻找最佳参数，而是为了观察价值传递的先后顺序。

## 为什么第一轮只让位置 3 得到高价值

第一轮从位置 0 向右走时，位置 1、2、3 的 Q 值还都是零。程序按正向顺序边走边更新：

```text
先更新位置0，再更新位置1，再更新位置2，最后更新位置3
```

直到最后一步到达终点时，`Q(位置3,right)` 才得到终点奖励 `1.0`。此时位置 2 的更新已经做完了，不能回头重算。因此需要下一轮练习，位置 2 才能读取位置 3 已经学到的高价值。

## 预期传播顺序

```text
第1轮：位置3知道右边是终点
第2轮：位置2读取位置3的价值
第3轮：位置1读取位置2的价值
第4轮：位置0读取位置1的价值
```

所以，奖励虽然发生在终点，但通过反复练习，较早动作也逐渐获得能反映未来结果的 Q 值。

## 运行方式

```bash
python examples/value_propagation_demo.py
```

## 本次实际结果

| 轮次 | 位置0-`right` | 位置1-`right` | 位置2-`right` | 位置3-`right` |
| --- | ---: | ---: | ---: | ---: |
| 初始 | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| 第1轮 | -0.0100 | -0.0100 | -0.0100 | **1.0000** |
| 第2轮 | -0.0100 | -0.0100 | **0.8900** | 1.0000 |
| 第3轮 | -0.0100 | **0.7910** | 0.8900 | 1.0000 |
| 第4轮 | **0.7019** | 0.7910 | 0.8900 | 1.0000 |

高价值实际按“位置 3 → 位置 2 → 位置 1 → 位置 0”的顺序出现，与预期一致。

位置 0 到位置 3 的最终数值不一样，是因为离终点越远，要经历更多次 `-0.01`，未来价值也会被折扣更多次。但它们最终都变成正数，表示向右带来的长期终点收益超过了途中扣分。

> [!success] 当前证据
> 纯 Python 受控演示实际运行成功，全部 20 项测试通过。这里只验证了玩具环境中的价值传播顺序。

## 本课边界

这个演示固定动作并使用学习率 `1.0`，只用于观察价值怎样传播。它没有研究探索效果，也不能代表一般训练中每轮一定只传播一个位置。

## 思考题

所有问题都基于上述固定条件：每轮依次经过位置 0、1、2、3，最后到达终点。

1. 第一轮中，为什么位置 3 的 `right` 能立即学到终点奖励，而位置 0 还不能立即知道完整的终点价值？
2. 第二轮更新位置 2 时，它从哪个位置读取未来价值？
3. 为什么要保留同一张 Q 表并训练多个 episode，价值才能逐渐传到位置 0？
4. 如果每个 episode 结束后都把 Q 表清零，第 4 轮时位置 0 能学到终点带来的长期价值吗？为什么？

## 回答记录

1. 第一轮更新位置 2 时，位置 3 的 Q 值还没有来得及更新，因此当时没有可用的未来价值。表述为“尚未更新”比“尚未探索”更准确。
2. 第二轮得到 `Q(位置2,right)=-0.01+0.9×1.0=0.89`。
3. 第三轮得到 `Q(位置1,right)=-0.01+0.9×0.89=0.791`。
4. 每轮清空 Q 表会移除跨轮递进过程，价值每次最多传播到最后一步，无法到达位置 0。

> [!success] 本课结论
> 后续位置已经保存的 Q 值，会在下一轮成为更早位置的未来价值；保留同一张 Q 表并反复练习，终点价值才能逐渐传播到起点。
