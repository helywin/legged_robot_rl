# 只改变 ε 的第一次对照实验

## 什么是单变量对照

如果同时改变训练轮数、学习率、折扣因子和 ε，结果发生变化时，我们无法判断是谁造成的。

因此这次保持其他条件相同，只改变 ε：

| 条件 | 设置 |
| --- | --- |
| 环境 | 同一个五格走格子环境 |
| 训练轮数 | `500` |
| 学习率 | `0.20` |
| 折扣因子 | `0.90` |
| 随机种子 | `0` |
| 评估 | 关闭探索、停止更新，运行 10 轮 |
| 唯一变量 | `ε=0.0`、`0.2`、`1.0` |

这种只改变一个因素的比较，叫作**单变量对照**。

## 先分清两个问题

本次同时记录两类结果：

1. **训练期间到达目标次数**：包含 ε 带来的随机动作；
2. **训练后评估**：关闭探索，用于查看 Q 表学到的最佳动作。

训练期间走得随机，不等于 Q 表一定没有学到东西。反过来，训练期偶然成功，也不能单独证明策略已经稳定。

## 实际结果

| ε | 训练期间到达目标 | 关闭探索后的成功率 | 平均步数 | 平均奖励 |
| ---: | ---: | ---: | ---: | ---: |
| `0.0` | 499/500 | 10/10 | 4.00 | +0.97 |
| `0.2` | 497/500 | 10/10 | 4.00 | +0.97 |
| `1.0` | 158/500 | 10/10 | 4.00 | +0.97 |

## 怎样解释 ε=1.0

`ε=1.0` 表示训练时每一步都随机选择动作，所以训练期间只有 158/500 轮到达目标。但随机动作也给了 Q 表大量不同经验；500 轮后，Q 表仍然学到每个非终点位置的 `right` 更好。

评估时关闭探索，策略不再随机，因此得到 10/10、平均 4 步。

这说明：

```text
训练期间执行的动作是否稳定
和
训练后 Q 表保存的最佳动作是否正确
不是同一个问题
```

## 为什么 ε=0.0 也学会了

这次 `ε=0.0` 也得到 10/10，但不能由此得出“探索没有用”。当前小程序还有两个有利条件：

1. Q 值相同时，会在并列动作中随机选择；
2. 错误动作得到 `-0.01` 后，仍为零的未尝试动作会显得更好。

所以即使 ε 为零，程序仍可能因为并列随机和负奖励尝试另一个动作。环境又非常简单，500 轮足以学会。

> [!warning] 结论边界
> 本实验只有一个随机种子和一个简单环境。它能说明这一次运行发生了什么，不能证明任意环境中 `ε=0` 都能学习，也不能找出“最佳 ε”。

## 思考题

以下问题都基于表中的实际结果：

1. 为什么 `ε=1.0` 训练期间只成功 158/500，关闭探索后却能评估成功 10/10？
2. `ε=0.0` 这次评估成功 10/10，能否证明探索永远没有用？请结合“并列随机”和负奖励解释。
3. 三组实验中，哪些条件保持不变，唯一改变的是什么？为什么不能同时改变学习率？
4. 如果评估 `ε=1.0` 训练出的 Q 表时仍保持 `ε=1.0`，评估动作会稳定吗？这能准确反映 Q 表中的最佳策略吗？

## 第一次回答记录

1. 已理解关闭探索后会根据各位置的最佳 Q 值行动。需要订正：`ε=1.0` 不是“更倾向探索”，而是每一步都进入探索并随机选择动作。
2. 已认识到完全不探索可能无法充分尝试动作。更准确地说，策略可能过早利用当前看似最好的动作，从未发现尚未尝试但实际更好的动作；不一定要先成功一次才会发生。
3. 正确：固定训练轮数、学习率、折扣因子和随机种子，唯一改变探索概率 ε。环境与评估方式也保持不变。
4. 需要订正：即使 Q 表已经学好，评估时 `ε=1.0` 仍会让每一步随机选动作，因此行为不稳定，也不能准确展示 Q 表保存的最佳策略。

> [!important] Q 表学好不等于动作一定稳定
> 动作是否稳定还取决于执行时怎样从 Q 表选择动作。`ε=0` 才会一直利用最高 Q 值；`ε=1` 会忽略最高 Q 值并始终随机探索。

## 订正回答

1. `ε=0` 时选择最高 Q 值的 `right`，不是随机动作。
2. `ε=1` 时不一定选择 `right`，因为每次都随机探索。
3. 评估仍保留探索时，得到的是“最佳策略与随机动作混合后的表现”，不是 Q 表中最佳策略本身的表现。三题均回答正确。

> [!success] 本课结论
> ε 控制执行动作时探索和利用的比例。训练过程与关闭探索后的评估必须分开，才能判断 Q 表保存的最佳策略。
