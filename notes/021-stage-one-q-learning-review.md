# 纯Python Q-learning阶段综合复习

## 复习目标

本课不增加新概念，用一个完整场景检查是否已经能读懂纯Python Q-learning训练循环。

通过标准：

1. 能按顺序说明一个episode和一个step；
2. 能指出环境、策略和Q表各自负责什么；
3. 能说明一次更新读取与修改哪些Q值；
4. 能区分ε、学习率和gamma；
5. 能区分训练表现与关闭探索后的评估。

## 完整场景

五格环境如下：

```text
位置0 → 位置1 → 位置2 → 位置3 → 终点4
```

环境规则：

- 动作是`left`或`right`；
- 普通一步奖励为`-0.01`；
- 到达终点奖励为`+1.00`；
- 每个episode最多10步；
- 到达终点或步数用完时，`done=True`。

训练配置：

```text
ε=0.20
学习率=0.20
gamma=0.90
```

某一次step开始前：

```text
当前观察=位置2
Q(位置2,left)=0.30
Q(位置2,right)=0.60
```

策略通过ε-greedy选择`right`。环境执行后返回：

```text
新观察=位置3
奖励=-0.01
done=False
```

位置3的Q值为：

```text
Q(位置3,left)=0.20
Q(位置3,right)=0.80
```

因此本次更新：

```text
下一位置最高Q值=0.80
目标值=-0.01+0.90×0.80=0.71
旧Q值=Q(位置2,right)=0.60
差距=0.71-0.60=0.11
修正量=0.20×0.11=0.022
新Q值=0.60+0.022=0.622
```

最终只执行：

```text
Q(位置2,right): 0.60 → 0.622
```

## 综合题

以下四题都基于上面的完整场景：

1. 请从episode开始说起，按顺序描述训练循环，至少包含`reset`、观察、ε-greedy、动作、环境返回、Q值更新和`done`。
2. 这次step中，哪个数据由策略产生？环境返回哪三个数据？Q表读取了哪些值？最终只修改哪个格子？
3. 为什么目标值是`0.71`，最终写回Q表的却是`0.622`？请说明gamma和学习率分别在哪一步起作用。
4. 训练500轮时仍保留`ε=0.20`并持续更新Q表；训练后评估时设`ε=0`并停止更新。两种运行分别想观察什么？为什么不能只用训练期间的成功次数判断策略已经学会？

## 通过后的下一阶段

如果能正确解释以上问题，说明已经达到阶段一的理解目标。下一阶段才进入标准Python环境接口，学习`reset()`、`step()`、动作空间以及“到达终点”和“超过步数限制”的区别；仍然不直接进入Go2。
