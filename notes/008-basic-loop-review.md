# 基础闭环综合复习

目前已经学过：

- [[002-observation-and-action|观察和动作]]；
- [[003-reward|奖励]]；
- [[004-rl-environment|环境]]；
- [[005-policy|策略]]；
- [[006-step|交互步]]；
- [[007-episode|一轮练习]]。

它们组成完整闭环：

```text
观察 → 策略 → 动作 → 环境
 ↑                    ↓
 └──── 新观察和奖励 ──┘

完成一次循环 = 一个 step
从开始到摔倒、超时或完成 = 一个 episode
```

## 综合题

1. 请把下面四项排成一个循环：`环境计算结果`、`策略选择动作`、`得到观察`、`发出动作`。
2. 机器狗连续执行 500 个 step，没有摔倒，但到达规定时间后环境将它重置。这是多少个 episode？为什么？
3. 如果奖励只看“向前移动距离”，完全不关心是否平稳，策略可能学出哪些我们不想要的行为？至少举一个例子。
4. 训练完成后只是回放策略时，策略还需要先看到本 step 的奖励，才能选择当前动作吗？请根据闭环中各部分的顺序说明理由。

## 答题记录与辨析

- 第 1 题：正确。循环可以从任意位置开始描述；按本次回答是“环境计算结果 → 得到观察 → 策略选择动作 → 发出动作 → 回到环境计算结果”。
- 第 2 题：正确。超时也是一轮结束，所以是 1 个 episode；重置后才开始下一轮。
- 第 3 题：正确，而且例子很好。策略可能趴在地上滑行，或者为了距离高速横冲直撞。
- 第 4 题：需要继续区分训练和回放。

奖励在**训练时**用于调整策略，让策略逐渐学会更好的选择。但是策略训练完成后，在一次普通回放中，决策顺序是：

```text
当前观察 → 已训练好的策略 → 当前动作
```

策略通常不读取当前 step 的奖励来选择当前动作。环境仍然可以计算奖励，用于统计表现，但奖励不是已训练策略的直接输入。

## 追问

1. 回放时机器狗身体向左倾斜，策略要选择当前动作。它直接需要的是“身体倾斜等观察”，还是“当前奖励”？
2. 假设保持同一个已训练策略、给它完全相同的观察，只把环境里的奖励计算规则改掉，但不重新训练。策略此刻输出的动作通常会不会立刻改变？为什么？

## 追问回答

- 回放时，策略直接需要身体倾斜等观察。
- 使用同一个已经训练好的策略回放时，只修改奖励规则而不重新训练，策略对相同观察的动作通常不会立刻改变。

至此已经能区分：训练时奖励用于塑造策略；回放时固定策略根据观察生成动作。
