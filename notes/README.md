# 学习笔记

这里记录学习过的概念。课程同时服务于四足机器人盲走楼梯和 DQN 游戏智能体两个目标；入门阶段先用直觉与纯 Python 小环境理解，后续再分别补充游戏和机器人代码、配置或实验依据。

基础笔记先回答三件事：

1. 这个概念解决什么问题？
2. 用走格子、游戏或机器狗举一个最简单的例子。
3. 学完后应该能用自己的话说清什么？

等进入实际任务后，再补充它在 DQN 游戏环境或 Go2 配置中的位置、实验现象和未验证内容。两个目标的验证证据不能混用。
