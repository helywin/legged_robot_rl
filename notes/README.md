# 学习笔记

这里记录学习过的概念。入门阶段先用直觉和机器狗例子理解，后续再逐步补充代码、配置或实验依据。

基础笔记先回答三件事：

1. 这个概念解决什么问题？
2. 用机器狗举一个最简单的例子。
3. 学完后应该能用自己的话说清什么？

等进入实际任务后，再补充它在 Go2 配置中的位置、实验现象和未验证内容。
