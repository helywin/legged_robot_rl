# 一次奖励如何更新 Q 值

## 先分清 Q 表和一个 Q 值

- **Q 表**是整张表；在简单离散环境中，可以用二维矩阵表示；
- 每一行对应一种观察，每一列对应一个动作；
- **一个 Q 值**只是其中一个格子，表示某个观察下选择某个动作的经验分数。

如果环境有 3 种观察、4 个动作，Q 表里共有 `3 × 4 = 12` 个 Q 值。在“位置 1”执行“向下”后，只更新 `Q(位置1, 向下)`，不是更新整张表。

> [!success] 回答记录
> 已正确回答：共有 12 个值，只更新“位置 1”的“向下”对应的格子。

## 本课只处理最后一步

先假设小人执行动作后立刻结束这一轮。这样暂时不考虑更远的将来，只观察：旧 Q 值如何根据这一次奖励改变。

假设：

- 当前 Q 值是 `0.30`，表示原来的经验判断；
- 这次实际奖励是 `1.00`；
- 新结果比原来的判断高，两者相差 `1.00 - 0.30 = 0.70`。

我们通常不因为一次结果就直接把 Q 值从 `0.30` 改成 `1.00`，而是只朝它移动一小步。

## 学习率

**学习率**表示：这一次吸收新信息时，要走完差距的多大比例。

如果学习率是 `0.20`，就吸收差距的 20%：

```text
旧 Q 值：  0.30
实际奖励： 1.00
差距：     0.70
本次修正： 0.70 × 0.20 = 0.14
新 Q 值：  0.30 + 0.14 = 0.44
```

先用普通话概括：

> 新 Q 值 = 旧 Q 值 + 学习率 ×（实际结果与旧判断的差距）

写成代码就是：

```python
new_q = old_q + learning_rate * (reward - old_q)
```

## 为什么只改一部分

单次奖励可能带有偶然性。如果一次幸运结果就完全覆盖过去经验，Q 值容易忽高忽低。只吸收一部分，可以把新体验和过去经验结合起来。

| 学习率 | 效果 |
| ---: | --- |
| `0` | 完全不学习，Q 值不变 |
| `0.2` | 每次吸收当前差距的 20% |
| `1` | 完全采用这一次结果 |

## Python 演示

```bash
python examples/q_value_update_demo.py \
  --initial-q 0.3 --reward 1.0 --learning-rate 0.2 --updates 4
```

这个程序重复收到相同奖励，展示 Q 值如何逐渐接近 `1.00`。它还不是完整的 Q-learning：本课没有考虑下一位置的价值，也没有训练完整走格子策略。

本次实际运行得到：

```text
初始 Q=0.3000
第 1 次: 本次修正=+0.1400, 新 Q=0.4400
第 2 次: 本次修正=+0.1120, 新 Q=0.5520
第 3 次: 本次修正=+0.0896, 新 Q=0.6416
第 4 次: 本次修正=+0.0717, 新 Q=0.7133
```

Q 值越接近奖励 `1.00`，剩余差距越小，所以后面的修正量也逐渐变小。

## 思考题

1. 旧 Q 值是 `0.30`，实际奖励是 `1.00`，两者的差距是多少？
2. 学习率是 `0.20` 时，这次应修正多少？新 Q 值是多少？
3. 学习率分别为 `0` 和 `1` 时，Q 值会怎样更新？
4. 如果奖励有时很幸运、有时很倒霉，为什么学习率不一定越大越好？

## 回答记录

1. 差距是 `1.00-0.30=0.70`。
2. 修正量是 `0.20×0.70=0.14`，新 Q 值是 `0.30+0.14=0.44`。
3. 更新 `Q(位置1, 向下)` 时，其他动作对应的 Q 值不会跟着改变。
4. 奖励在 `+1` 和 `-1` 之间波动时，学习率设为 `1` 会让 Q 值剧烈波动，难以稳定。

> [!success] 本课结论
> 一次经历只更新对应观察和动作的一个 Q 值；学习率决定这个格子朝新结果移动多大一步。
