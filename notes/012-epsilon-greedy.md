# ε-greedy：控制探索概率

## ε 是什么

`ε` 是希腊字母 epsilon，这里把它读作“艾普西隆”。它表示：**每次选择动作时，进入探索的概率**。

例如 `ε = 0.2`：

- 每次决策有 20% 的概率探索，随机选择动作；
- 每次决策有 80% 的概率利用，选择 Q 分数最高的动作。

如果重复决策 100 次，通常会有大约 20 次探索，但不保证刚好是 20 次。因为每一次是否探索都是随机的，就像抛硬币 100 次不一定正好有 50 次正面。

| ε | 选择方式 |
| ---: | --- |
| `0` | 从不探索，总是利用 |
| `0.2` | 约 20% 探索、约 80% 利用 |
| `1` | 总是探索，从不利用 |

## ε-greedy 的一次决策

```text
先随机判断这一次是否探索
├─ 是：随机选择 left 或 right
└─ 否：选择 Q 分数更高的动作
```

这里的 **greedy（贪心）** 是指：只看当前 Q 表，选择分数最高的动作。

> [!important] 两种统计不要混淆
> “进入利用”不等于“动作是 right”。探索时随机选择，也可能恰好选到 `right`。因此，`right` 的总次数通常会多于“利用”的次数。

## Python 演示

示例使用固定分数 `left=0.30`、`right=0.80`，只演示如何选择动作，**还没有学习或更新 Q 表**。

```bash
.venv/bin/python -m examples.epsilon_greedy_demo --epsilon 0.2 --decisions 100 --seed 0
```

`seed` 固定后，同一台环境重复运行会得到相同结果，方便我们检查。它不会取消随机选择，只是让这串随机结果可以复现。

本次实际输出：

```text
选择方式: 探索=13, 利用=87
最终动作: left=7, right=93
```

虽然 `ε=0.2`，这 100 次只出现了 13 次探索，但决策次数继续增加后，探索比例通常会逐渐接近 20%。此外，13 次探索里有 6 次随机选到了 `right`，加上 87 次利用选择的 `right`，最终一共得到 93 次 `right`。

## 训练和回放

- 训练早期通常使用较大的 ε，多尝试不同动作；
- 后续通常逐渐减小 ε，更多使用已经学到的经验；
- 回放或评估时通常设为 `ε = 0`，观察策略本身是否稳定。

## 思考题

1. 当 `ε = 0.2`，决策很多次时，大约百分之多少是探索，百分之多少是利用？
2. `ε = 0` 和 `ε = 1` 分别会发生什么？
3. 固定 Q 分数为 `left=0.30`、`right=0.80`。程序统计出 80 次“利用”，最终却有 90 次 `right`，这矛盾吗？为什么？
4. 如果训练一开始就把 ε 从 `1` 突然改成 `0`，而 Q 表还不可靠，可能有什么问题？

## 第一次回答记录

1. `ε=0.2` 时，约 20% 探索、80% 利用。正确。
2. 回答“只探索不利用”。这是 `ε=1` 的情况，还需要补充 `ε=0`。
3. 回答“样本太小不足以反映概率”。样本大小会影响实际探索比例是否接近 ε，但这里问的是为什么 `right` 次数可以多于利用次数。
4. Q 表还不是最优的，突然停止探索可能错失更好的动作。正确。

> [!example] 第 3 题拆解
> 80 次利用全部选择 Q 分数更高的 `right`。剩余 20 次探索中，如果随机得到 10 次 `right`、10 次 `left`，最终就是 `right=80+10=90`、`left=10`。因此没有矛盾。

> [!note] 样本大小影响什么
> `ε=0.2` 只表示每次有 20% 概率探索。决策次数少时，实际探索比例可能明显偏离 20%；次数很多时，通常才会逐渐接近 20%。这和“探索时最终随机选了哪个动作”是两个不同问题。

## 订正回答

1. 回放时希望动作稳定，应设为 `ε=0`。
2. 80 次利用得到 80 次 `right`；20 次探索得到 6 次 `right` 和 14 次 `left`，所以最终是 `right=86`、`left=14`。
3. 不能因为 100 次中只有 13 次探索就判断程序错误。`ε=0.2` 表示每次决策的探索概率，不是强制规定实际次数比例。

> [!success] 本课结论
> ε 控制每次决策进入探索的概率；它不直接规定最终动作，也不保证少量决策中出现固定比例的探索。
