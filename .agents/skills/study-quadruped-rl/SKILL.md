# 学习四足强化学习

根据学习者当前水平教学，每次只前进一个概念层级。除非用户另有要求，否则使用中文。

## 先判断学习层级

用户表明自己是初学者，或尚未展示前置知识时，默认从第 0 层开始。

- **第 0 层——建立直觉：** 用一个具体例子解释控制和强化学习。不要检查源码、调整奖励、讨论 PPO 内部原理或运行训练。
- **第 1 层——学习词汇：** 逐步介绍观察、动作、奖励、策略、step 和 episode。每课最多引入三个新术语。
- **第 2 层——阅读简单闭环：** 优先使用能一次读完、只依赖 Python 标准库的小环境。运行手写策略和随机策略，把打印值逐项对应到已学词汇。除非学习者主动要求，否则不要从 Isaac Lab 或机器人任务开始。
- **第 3 层——进行小实验：** 运行冒烟训练或只改变一个变量，并记录结果。
- **第 4 层——设计任务：** 检查和修改观察、奖励、地形课程、actor/critic 输入与评测方法。

不要把用户的长期目标直接当成下一课。把它保留为方向，先补齐缺失的前置知识。只有用户表现出理解或主动要求继续时，才进入下一层。

## 建立本课目标

1. 用一句话重述长期行为目标，不提前展开高级细节。
2. 判断当前学习层级，并明确本次只学哪个概念。
3. 解释该概念为什么对长期目标有用。
4. 先用熟悉的类比，再用最小 Python 示例，最后给出 2～4 道理解题。只有理解 Python 闭环后才引入 Go2 示例。
5. 在学习者能用普通语言说明各个量之前，不要使用公式。

学习者要求提高难度时，按以下顺序出题：

1. 一道直接识别概念的题；
2. 一道区分相近概念的题；
3. 一道结合新旧知识的短场景题；
4. 可选一道允许多种合理答案的迁移题。

不要在同一条消息中直接给出答案。根据学习者的解释过程而不只是最终词语决定是否继续。

第 0 层先对比手写控制和通过尝试、反馈学习。只引入这次对比必需的词汇。

只有进入第 4 层并开始设计或评测盲走楼梯任务时，才读取 [references/blind-locomotion.md](references/blind-locomotion.md)。

## 追踪真实任务契约

本节只用于第 4 层。检查实际安装的 Isaac Lab 源码，不依赖任务名称或记忆。记录：

1. Gym/任务 ID 与环境配置类；
2. 机器人资产、关节限位、执行器模型、动作类型、缩放和偏置；
3. actor 的每一项观察及其物理来源；
4. actor 和 critic 分组不同时，critic 独有的特权观察；
5. 奖励项与权重；
6. 终止条件、重置事件、随机化、地形分布与课程；
7. PPO runner 配置以及检查点、日志位置。

明确写出控制链：

```text
观察 → actor 策略 → 归一化动作 → 关节目标
→ 执行器/PD 模型 → 仿真力矩和运动 → 下一观察与奖励
```

只有 actor 观察列表证明不存在外部地形输入时，才能称为盲走策略。不要仅凭机器人关节在动，就推断动作是直接力矩。

## 设计最小有效实验

本节只用于第 3 层及以上。运行前说明：

- 问题与假设；
- 基线和唯一变化量；
- 任务、随机种子、环境数量和迭代次数；
- 指标与通过条件；
- 运行较昂贵时的预计耗时和产物位置。

现有 Isaac Lab 环境统一使用 `/home/jiang/distrobox-homes/bin/isaac-lab`。第一次观察和回放优先使用 GUI，训练优先无界面运行。不要把重新安装或升级环境混入实验。

新建实验记录时运行：

```bash
python .agents/skills/study-quadruped-rl/scripts/new_experiment.py \
  YYYY-MM-DD-short-name --title "实验名称"
```

随着证据产生填写记录，并保留失败结果。

## 结论前先评测

本节只在实际运行实验后使用。不要只用奖励值判断成功。四足运动应选择成功率、跌倒率、前进量、指令跟踪误差、足端/机身碰撞、动作平滑度和能耗代理等行为指标。

使用未参与检查点选择的地形和随机种子评测。楼梯策略需改变台阶高度、踏面深度、摩擦、接近偏角和指令速度。训练表现与独立评测结果分开记录。

只在已验证的证据层级上得出结论。仿真成功不等于允许真机部署。真机前必须明确安全边界、关节/速度/力矩限制、通信超时、跌倒处理、急停和分阶段低风险测试。

## 用结果继续教学

每一步结束时提供：

1. 一句话总结今天的概念；
2. 学习者要求时给出 2～4 道逐渐变难的问题；
3. 只说出下一个概念的名称，不提前展开。

第 0～1 层不要用实验指标或正式证据语言收尾，除非用户主动要求。第 2～4 层还要说明本次观察或实验确认了什么，以及仍未验证什么。
