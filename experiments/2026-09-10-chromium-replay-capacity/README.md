# 真实经验回放容量对照

## 问题、假设与唯一变化量

用同一采样/保存代码读取6条真实经验。只将缓冲容量从4改为6，验证前者淘汰最旧2条、后者全部保留；每次随机抽样不删除已有经验。采样批次固定为先1条再5条，抽样请求始终2条。

## 环境与配置

1个原生同步第一关GUI，初始化IDLE1tick，再6次RIGHT，每次1tick；每步0.3秒，批间1秒，末尾2秒，0次网络更新。K=2、17项观察及既有尺度不变，分数差奖励/100，动作ID4。回放随机对象random.Random(7)在外层创建一次，两批共用；固定的是回放抽样，不是游戏seed。原生无公共seed/reset，不要求两个进程完整状态一致。复用当前.venv与子模块构建。

## 完整命令与学习者操作

```bash
.venv/bin/python experiments/2026-09-10-chromium-replay-capacity/run.py --capacity 4
.venv/bin/python experiments/2026-09-10-chromium-replay-capacity/run.py --capacity 6
```

每次预计十几秒内结束。比较第二批之后的保存编号和抽样编号，观察再次抽样后保存编号是否保持不变。编号1..6只用于追踪，不进入策略观察。学习者需要运行并报告保存范围和抽样是否删除内容，不需要修改代码或复制教师固定坐标。

## 产物与指标

产物为终端输出，无模型、数据集或视频。指标：实际6条/6tick；首批库存1返回空抽样；满容量后保留最近capacity条；抽取2条完整对象；抽样不删除；入库和抽样不推进游戏；相邻采集观察保持衔接。提前终止或中断时不把未满6条的结果记为完整容量对照。

## 教师结果（2026-09-10）

两组真实GUI模式运行均正常退出，首批保存[1]并抽到[]。容量4：保存[3,4,5,6]，首次抽[5,3]，再次抽[6,5]后保存不变。容量6：保存[1,2,3,4,5,6]，首次抽[3,2]，再次抽[4,1]后保存不变。均6tick/6条，各项断言通过。经验5的x观察0.093→0.126、经验3为0.039→0.063；实际动作4，reward=0，terminated=False。

没有独立截图审阅画面，不把原生启动和终端接口证据说成完整视觉验收。早期无新增分数，未验证非零奖励轨迹或终止后的回放，本课也未训练网络。
