# Chromium 冻结模型与随机策略对照

## 问题与假设

首个短训练模型是否在固定20个开局下比均匀随机动作得分更高？预期可能有得分优势，但500次更新不足以预设稳定生存或通关。唯一比较因素为动作选择策略。

## 环境与配置

原生游戏评测；单个游戏实例顺序运行，模型/随机各20局，不进行训练。CPU，native chromium-bsu-rl/seeded-reset-v3；task-v1、62维观察、18动作、每动作5 tick，每局最多250决策。双方游戏种子201至220，随机动作种子100000+游戏种子。模型贪心、参数冻结。

检查点：`exercises/chromium_dqn/runs/train-06fbbc3a5a1c4ff78afc7ffabb1586c1/policy.pt`。
SHA256：`f71681ec65e1e2a444900a2bd9603f5015dab8fc6cc92c7fc5cf06928244bbe2`。

配对得分15胜1平4负。平均得分差1775（36.7%），中位数差87.5（1.75%）。本组结果支持得分优势，但没有过关证据。

## 边界与下一个问题

这是受限时长的原生游戏评测，不是完整游戏验收或机器人验证。种子相同控制初始随机条件，不保证不同动作产生相同后续弹幕。20局描述性结果不代表统计显著或普遍优势。后续若用这些种子改进模型，它们属于开发集，最终验收应使用未参与选择的新种子。

下一步：用接近模型中位数的seed209复盘位置、动作、损命与奖励关系，不根据单局断言奖励设计是唯一原因。
