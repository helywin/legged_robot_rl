# 实验记录

每项实验使用独立目录，例如：

```text
experiments/2026-08-06-go2-smoke-training/
└── README.md
```

实验记录模板：

```markdown
# 实验名称

## 问题

这次实验只想弄清楚什么？

## 假设

预期会看到什么，为什么？

## 环境与配置

- Isaac Lab 版本或提交：
- 任务名称：
- 并行环境数：
- 训练迭代数：
- 随机种子：
- 只改变的变量：

## 命令

```bash
# 可直接复现的完整命令
```

## 产物

- 日志位置：
- 检查点位置：
- 图表或视频位置：

## 观察

记录关键指标、现象和异常，不只记录“成功”或“失败”。

## 结论

数据是否支持假设？

## 未验证与下一步

哪些结论仍然不能从本实验得到？下次只继续验证什么？
```
