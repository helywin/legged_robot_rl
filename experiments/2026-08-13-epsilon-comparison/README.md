# 走格子环境的探索概率对照实验

## 问题

在其他配置不变时，训练探索概率 ε 怎样影响训练期间表现和关闭探索后的评估结果？

## 假设

ε 越高，训练期间的动作越随机，因此到达目标次数可能下降。但即使训练动作不稳定，Q 表仍可能从大量尝试中学到最佳动作，必须通过关闭探索后的评估单独判断。

## 环境与配置

- 证据级别：纯 Python 玩具环境受控实验
- Isaac Lab 版本或提交：不适用，未启动 Isaac Lab
- 任务名称：五格 LineWorld
- 并行环境数：1
- 训练迭代数：每组 500 个 episode
- 随机种子：0
- 学习率：0.20
- 折扣因子：0.90
- 评估：关闭探索、停止更新，每组 10 个 episode
- 基线：ε=0.20
- 只改变的变量：ε，取 0.0、0.2、1.0

## 命令

```bash
python examples/train_line_world_q_learning.py --epsilon 0
python examples/train_line_world_q_learning.py --epsilon 0.2
python examples/train_line_world_q_learning.py --epsilon 1
```

- 日志位置：本记录中的结果表；程序只输出到终端
- 检查点位置：无，Q 表未保存到文件

## 观察与指标

| ε | 训练期间到达目标 | 评估成功率 | 评估平均步数 | 评估平均奖励 |
| ---: | ---: | ---: | ---: | ---: |
| 0.0 | 499/500 | 10/10 | 4.00 | +0.97 |
| 0.2 | 497/500 | 10/10 | 4.00 | +0.97 |
| 1.0 | 158/500 | 10/10 | 4.00 | +0.97 |

观察：ε=1.0 时训练期成功次数明显较低，因为动作始终随机；但关闭探索后仍能连续向右到达终点。

ε=0.0 仍然学会，是因为当前实现在最高 Q 值并列时随机选择，而且负奖励会使已尝试的错误动作低于尚未尝试的零值动作。这不等于一般情况下不需要探索。

## 结论

数据支持假设：提高到 ε=1.0 后，训练期到达目标次数从基线的 497/500 降到 158/500；但三组关闭探索后的评估均为 10/10。

本次结果说明训练期行为和训练后利用策略必须分开观察。结论只适用于当前代码、五格环境、500 轮和随机种子 0。

## 未验证与下一步

- 只运行一个随机种子，不能判断结果波动；
- 环境过于简单，不能证明复杂任务中 ε=0 也能学习；
- 没有比较学习速度随 episode 的变化；
- 不能从三组数据找出通用的最佳 ε；
- 不涉及 Gymnasium、Isaac Lab、四足机器人或真机。

下一步只比较多个随机种子下的结果稳定性，或只改变一个其他参数；不同时改变多项配置。
