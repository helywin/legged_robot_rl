# 一批误差怎样合成一次参数更新

## 本课只增加一个概念

第 50 课已经得到一批所选动作预测：

```text
selected_q_values = [-0.05, 0.60]
```

每条经验都有自己的 target，因此会产生两个误差。但是 `backward()` 要从一个标量 loss 出发，本课只回答：

> 怎样保留每条经验各自的误差贡献，同时把它们合成一次稳定的参数更新？

这里的新操作是**取平均**。它不是让两条经验互相修改 target，而是先分别算损失，再让两份梯度按相同比例共同作用于共享参数。

## 1. 固定数据从哪里来

仍使用第 50 课的两条观察与实际动作：

| 经验 | 观察 | 实际动作 | 在线网络所选 Q 值 |
| ---: | --- | ---: | ---: |
| 0 | `[0.2, -0.1]` | 1 | -0.05 |
| 1 | `[-0.3, 0.4]` | 0 | 0.60 |

为了只学习批量损失，本课直接给出已经算好的无梯度 target：

```text
target_q_values = [1.01, 0.20]
```

- 第 0 条的 `1.01` 沿用第 49 课“奖励 + 折扣后的未来价值”；
- 第 1 条的 `0.20` 表示这条经验希望动作 0 的预测向较小方向移动；
- 两个 target 都是本轮参照，不参与梯度计算。

## 2. 先分别算每条经验的损失

问题是：每条经验当前预测离自己的 target 有多远？

第 0 条：

```text
prediction = -0.05
target     =  1.01
误差       = -0.05 - 1.01 = -1.06
平方损失   = (-1.06)² = 1.1236
```

第 1 条：

```text
prediction = 0.60
target     = 0.20
误差       = 0.60 - 0.20 = 0.40
平方损失   = 0.40² = 0.1600
```

所以逐条损失张量为：

```text
per_item_losses = [1.1236, 0.1600]
per_item_losses.shape = (2,)
```

此时还没有修改参数。

## 3. 为什么要得到一个标量 loss

一次 `backward()` 需要明确“整体训练目标”怎样随参数变化。最常见的做法是取这一批逐条损失的平均：

$$
loss=\frac{1.1236+0.1600}{2}=0.6418
$$

代码中的职责是：

```text
per_item_losses.shape = (2,)
          ↓ mean
loss.shape = ()
```

形状 `()` 表示标量张量。它仍是张量，也仍通过每条 `per_item_loss` 连到相应的在线预测和共享参数。

## 4. 平均以后，每条经验会不会消失

不会。`mean()` 的计算图仍保留两条输入路径：

```text
经验0 → selected_q_0 → loss_0 ─┐
                                ├→ mean loss → backward
经验1 → selected_q_1 → loss_1 ─┘
```

平均只把每条经验的梯度乘以 $1/2$ 后相加。对本课两个预测值：

```text
第0条对 selected_q_0 的梯度
= 2 × (-1.06) / 2
= -1.06

第1条对 selected_q_1 的梯度
= 2 × 0.40 / 2
= 0.40
```

负梯度使第 0 条预测在 SGD 更新后增大，正梯度使第 1 条预测在 SGD 更新后减小。两条经验指向不同动作输出行，但最终都累加到同一个在线网络的参数 `.grad` 中。

## 5. 为什么通常用平均而不是求和

如果使用求和，批量从 2 条变成 20 条时，梯度通常也会随经验数量变大，原来的学习率含义会改变。取平均后，每次更新表示“这一批经验的平均意见”，更新尺度对批量大小更稳定。

这不代表不同批量一定产生相同梯度，因为抽到的经验内容仍然不同；它只避免单纯因为条数增加就把梯度整体放大。

## 6. 本课数字更新后会怎样

本课使用 SGD 学习率 `0.1`。一次平均损失更新后：

```text
selected_q_before = [-0.05, 0.60]
target_q_values   = [ 1.01, 0.20]
selected_q_after  = [ 0.0613, 0.55]
```

逐项观察方向：

- 第 0 条从 `-0.05` 增大到 `0.0613`，靠近 `1.01`；
- 第 1 条从 `0.60` 减小到 `0.55`，靠近 `0.20`。

整批平均损失也从：

```text
0.6418 → 0.5113
```

这里仍只调用一次 `optimizer.step()`。不是每条经验各更新一次，而是整批先共同形成梯度，再统一更新。

## 7. 完整数据和梯度接力

```text
本轮在线参数
  → 批量前向得到每行全部动作 Q 值
  → 逐行取得实际动作 Q 值
  → 每行与自己的 target 计算平方损失
  → mean 合成标量 loss
  → backward 把整批贡献写入在线参数.grad
  → optimizer.step 只执行一次
  → 下一轮批量前向使用新参数
```

| 操作 | 改变参数吗 | 为下一步留下什么 |
| --- | --- | --- |
| 批量前向与 `gather` | 否 | 连接参数的 selected Q 张量 |
| 逐条平方损失 | 否 | 每条经验自己的损失 |
| `mean()` | 否 | 连接所有经验的标量 loss |
| `backward()` | 否 | 在线参数的整批平均梯度 `.grad` |
| `optimizer.step()` | **是** | 更新后的在线参数 |

## 一句话总结

一批经验先分别计算自己的平方损失，再取平均形成一个标量 loss；`backward()` 把各条经验的平均贡献汇总到共享参数梯度，optimizer 最后只更新一次。
