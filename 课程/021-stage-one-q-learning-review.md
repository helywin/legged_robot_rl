# 纯Python Q-learning阶段综合复习

## 复习目标

本课不增加新概念，用一个完整场景检查是否已经能读懂纯Python Q-learning训练循环。

通过标准：

1. 能按顺序说明一个episode和一个step；
2. 能指出环境、策略和Q表各自负责什么；
3. 能说明一次更新读取与修改哪些Q值；
4. 能区分ε、学习率和gamma；
5. 能区分训练表现与关闭探索后的评估。

## 完整场景

五格环境如下：

```text
位置0 → 位置1 → 位置2 → 位置3 → 终点4
```

环境规则：

- 动作是`left`或`right`；
- 普通一步奖励为`-0.01`；
- 到达终点奖励为`+1.00`；
- 每个episode最多10步；
- 到达终点或步数用完时，`done=True`。

训练配置：

```text
ε=0.20
学习率=0.20
gamma=0.90
```

某一次step开始前：

```text
当前观察=位置2
Q(位置2,left)=0.30
Q(位置2,right)=0.60
```

策略通过ε-greedy选择`right`。环境执行后返回：

```text
新观察=位置3
奖励=-0.01
done=False
```

位置3的Q值为：

```text
Q(位置3,left)=0.20
Q(位置3,right)=0.80
```

因此本次更新：

```text
下一位置最高Q值=0.80
目标值=-0.01+0.90×0.80=0.71
旧Q值=Q(位置2,right)=0.60
差距=0.71-0.60=0.11
修正量=0.20×0.11=0.022
新Q值=0.60+0.022=0.622
```

最终只执行：

```text
Q(位置2,right): 0.60 → 0.622
```

## 一图流：完整训练循环（含公式）

与 `examples/train_line_world_q_learning.py` 逐行对应，数字为本课场景：

```text
              纯 Python Q-learning 完整训练流程图
   （每一格对应 examples/train_line_world_q_learning.py 的真实代码，
     数字取自 021 课场景：s=位置2, a=right）

══════════════════════ 初始化（只做一次）═════════════════════

    Q 表全零：5 个位置 × 2 个动作
    ε=0.20（探索概率） α=0.20（学习率） γ=0.90（折扣因子）
                          │
                          ▼
┌─ 外层循环：episode × 500 ──────────────────────────────────
│
│    observation = env.reset()            # 观察回到位置0
│                          │
│                          ▼
┌─ 内层循环：step（done=False 就继续）──────────────────────
│
│    ① 选动作 a —— ε-greedy（策略产生的只有这一个 a）
│    │    掷 p = rng.random()
│    │    p < 0.20 ──► 随机选 left/right        # 探索
│    │    p ≥ 0.20 ──► a = argmax Q(s,·)        # 利用（并列随机挑）
│    │
│    ② env.step(a) —— 环境返回且只返回三样东西
│    │    r    = 奖励（到终点 +1.00，普通步 -0.01）
│    │    s'   = 新观察（本例：位置3）
│    │    done = 是否结束（到终点 或 步数≥10）
│    │
│    ③ Q-learning 更新 —— 整个训练只有这一步写 Q 表
│    │    ┌─ 公式 ─────────────────────────────────
│    │    │ done=False : y = r + γ·max Q(s',·)    ← γ 在这
│    │    │ done=True  : y = r          # 没有下一步，未来记 0
│    │    │
│    │    │ Q(s,a) ← Q(s,a) + α·( y - Q(s,a) )    ← α 在这
│    │    └───────────────────────────────────────
│    │    ┌─ 代入本例数字 ─────────────────────────
│    │    │ max Q(位置3,·) = 0.80     # 用更新前的 Q 表取 max
│    │    │ y   = -0.01 + 0.90 × 0.80            = 0.710
│    │    │ gap = 0.710 - 0.60                    = 0.110
│    │    │ new = 0.60 + 0.20 × 0.110            = 0.622
│    │    │ 写回且只写一格：Q[位置2][right] 0.60 ──► 0.622
│    │    └───────────────────────────────────────
│    │
│    ④ observation ← s'        # 新观察变成下一步的当前观察
│    │
│    ⑤ done == True ?
│         │
│         ├── 否 ──► 回到 ①（继续这一轮的下一步）
│         │
│         ▼ 是
│    episode 结束：停在位置4 则 successes += 1
└───────────────────────────────────────────────────────────
                          │
                          ▼
          （episode 计数 +1；不满 500 回到外层的 reset）
                          │
                          ▼
════════════ 500 轮结束：换一副面孔进入评估 ═════════════════

    ε = 0     → 不再随机，永远 a = argmax Q(s,·)
    Q 表冻结  → ③ 整个跳过，不再有任何写回
    统计行为：到达终点次数、平均步数、平均总奖励

──────────────────────── 符号对照 ──────────────────────────
  s   当前观察（位置）          a   动作（left/right）
  r   这一步的奖励              s'  执行动作后的新观察
  Q(s,a)  “在 s 做 a 以后能拿多少总奖励”的估计（Q 表一格）
  y   目标值：这一步奖励 + 打折后的未来最好价值
  ε   探索概率（多常随机试）    α   学习率（每次朝 y 挪几分之几）
  γ   折扣因子（未来的价值打几折）

──────────────────── 职责分工（谁产生什么）──────────────────
  策略  ──► 只产生 ① 里的动作 a
  环境  ──► 只产生 ② 里的 r、s'、done
  Q 表  ──► ① 读取一行供比较；③ 读两处、只写回一格
```

训练循环 = 反复“ε-greedy 选动作 → 环境返回三样 → 用 y = r + γ·maxQ 朝目标挪一小步”，评估时关探索、冻结 Q 表只看行为
## 综合题

以下四题都基于上面的完整场景：

1. 请从episode开始说起，按顺序描述训练循环，至少包含`reset`、观察、ε-greedy、动作、环境返回、Q值更新和`done`。
2. 这次step中，哪个数据由策略产生？环境返回哪三个数据？Q表读取了哪些值？最终只修改哪个格子？
3. 为什么目标值是`0.71`，最终写回Q表的却是`0.622`？请说明gamma和学习率分别在哪一步起作用。
4. 训练500轮时仍保留`ε=0.20`并持续更新Q表；训练后评估时设`ε=0`并停止更新。两种运行分别想观察什么？为什么不能只用训练期间的成功次数判断策略已经学会？

## 通过后的下一阶段

如果能正确解释以上问题，说明已经达到阶段一的理解目标。下一阶段才进入标准Python环境接口，学习`reset()`、`step()`、动作空间以及“到达终点”和“超过步数限制”的区别；仍然不直接进入Go2。
