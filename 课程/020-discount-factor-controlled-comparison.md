# 只改变折扣因子的对照实验

## 本课问题

折扣因子常用`gamma`表示。它不控制探索，也不控制Q值一次改变多少，而是控制：**计算目标值时，保留多少下一位置的未来价值。**

```text
ε：是否随机探索
学习率：一次更新移动多大一步
gamma：保留多少未来价值
```

## 实验设计

| 条件 | 设置 |
| --- | --- |
| 环境 | 同一个五格走格子环境 |
| 训练轮数 | `500` |
| ε | `0.20` |
| 学习率 | `0.20` |
| 随机种子 | `0` |
| 评估 | 关闭探索、停止更新，运行10轮 |
| 唯一变量 | `gamma=0`、`0.5`、`0.9`、`1.0` |

主要观察各位置`right`的Q值。位置3离终点最近，位置0离终点最远。

## 实际结果

| gamma | 位置0-`right` | 位置1-`right` | 位置2-`right` | 位置3-`right` | 评估成功率 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| `0` | -0.010 | -0.010 | -0.010 | 1.000 | 0/10 |
| `0.5` | 0.107 | 0.235 | 0.490 | 1.000 | 10/10 |
| `0.9` | 0.702 | 0.791 | 0.890 | 1.000 | 10/10 |
| `1.0` | 0.970 | 0.980 | 0.990 | 1.000 | 10/10 |

## gamma为0时发生什么

非终点动作的目标值是：

```text
目标值 = 当前奖励 + gamma × 下一位置最高Q值
```

当`gamma=0`：

```text
目标值 = 当前奖励
```

位置0、1、2无论向左还是向右，眼前奖励都是`-0.01`，所以它们只学到两个动作都约为`-0.01`，无法看出`right`最终通向终点。

评估时两个动作并列，当前评估程序固定取第一列`left`，所以一直撞左边界，结果为0/10。训练期间曾随机到达目标，仍不能说明利用策略学会了。

## gamma怎样影响远处价值

位置3向右会直接获得终点奖励，因此四组的`Q(位置3,right)`都是`1.0`，不需要通过未来价值传播。

位置0离终点最远，终点价值要经过多次折扣才能到达：

```text
gamma=0.5 → Q(位置0,right)=0.107
gamma=0.9 → Q(位置0,right)=0.702
gamma=1.0 → Q(位置0,right)=0.970
```

gamma越大，远期终点奖励在传到较早位置时保留得越多。

## 为什么gamma为1时位置0不是1

即使`gamma=1`不折扣未来价值，从位置0到终点仍有三次普通步奖励`-0.01`，最后才得到`+1.00`：

```text
-0.01 - 0.01 - 0.01 + 1.00 = 0.97
```

因此`Q(位置0,right)=0.970`是符合环境奖励规则的结果。

## gamma是否越大越好

本环境路线短、终点明确，所以较大的gamma有利于看见远处奖励。但在更长、更不确定的任务中，较大的gamma会让许多遥远且不确定的结果都强烈影响当前判断，估计可能更难稳定。

> [!warning] 结论边界
> 本实验只能说明当前确定性五格环境中的现象，不能据此确定机器狗训练应使用哪个折扣因子。这里只运行了一个随机种子，也没有研究有噪声或长时间任务。

## 思考题

以下问题都基于本课五格环境：普通一步奖励为`-0.01`，到达终点奖励为`+1.00`。

1. `gamma=0`时，位置0的`left`和`right`都只看到即时奖励`-0.01`。为什么这会导致评估策略无法判断终点在右边？
2. `gamma=0.5`时`Q(位置0,right)=0.107`，`gamma=0.9`时变为`0.702`。这说明gamma控制什么？
3. 为什么不论gamma取多少，`Q(位置3,right)`都是`1.0`？
4. 请分别说明ε、学习率和gamma控制训练过程中的什么。

## 第一次回答记录

1. 正确：`gamma=0`会忽略下一位置的Q值，左右动作都只看到相同的即时奖励，因此无法利用远处终点加以区分。
2. 需要订正：gamma不控制“反向传播速度”，而控制未来价值每向前传一步时保留多少、衰减多少。
3. 正确：位置3执行`right`后直接到达终点，目标值就是当前终点奖励`1.0`，不需要下一位置价值。
4. ε控制随机探索概率；学习率更准确地说控制一次Q值更新的幅度；gamma控制未来价值的保留比例，不是传播速度。

> [!important] 价值传播不等于神经网络反向传播
> Q-learning在这里通过多个step和episode把终点价值逐渐传到更早位置，称为价值传播。神经网络中的反向传播是以后用于计算参数梯度的另一种过程。

## “保留比例”和“速度”的区别

假设当前奖励都是`-0.01`，下一位置最高Q值都是`0.80`：

```text
gamma=0.5 → 目标值=-0.01+0.5×0.80=0.39
gamma=0.9 → 目标值=-0.01+0.9×0.80=0.71
```

两组都在当前这一次更新中读取下一位置，没有谁“传播得更早”。区别是`gamma=0.9`保留了更多未来价值，所以目标值更大。

## 参数辨析订正

已正确表述：

```text
ε       → 控制随机探索的概率
学习率  → 控制一次Q值更新的幅度
gamma   → 控制未来价值的保留比例
```

上面的参数表述已经订正；数值计算与“保留比例/传播速度”辨析见下一节。

## 最终订正

1. `gamma=0.5`时目标值为`0.39`，`gamma=0.9`时目标值为`0.71`。
2. gamma从`0.5`增加到`0.9`，是让当前位置保留更多未来价值，不是让价值更早传播。两题均回答正确。

> [!success] 本课结论
> gamma控制目标值中保留多少未来价值；它不控制随机探索、单次更新幅度或价值传播需要几个episode。
