# 201 一串动作怎样分配最后的反馈

[[课程/200-policy-feedback|200]] 建立了 PPO 的整体关系。本课先解决数据上的问题：环境每一步只给当步奖励，怎样让先前的动作也获得后续结果的学习依据？当前为概念讲解，暂不安排编程；后续实作仍按 [[PPO及感知四足课程路线]] 推进。

## 一步没有奖励，不等于没有作用

设一个简化的躲避任务：开始面对一片弹幕，智能体经过移动最终进入安全区域。任务规则只在到达安全区域时给正奖励，中间步骤没有即时得分。这是特意选的稀疏奖励例子，用于说明延迟反馈；不是 PPO 的要求，也不是现有游戏的奖励配置或运行结果。

第一步离开危险位置，第二步穿过空隙，第三步进入安全区。奖励只在第三步出现，但第一步与第二步让后续成功成为可能。若只拿每步刚收到的奖励评价该动作，前面几步就缺少这次成功所带来的学习依据。

要保留的不只是孤立的一条动作记录，而是带有先后关系的交互经历。这种按时间排列的观察、动作与反馈序列，通常称为轨迹。它不是只指角色在地图上画出的路线，而是程序记录的交互序列。

## 奖励可以每步都有，阶段结果也可以用于学习

奖励由任务的奖励函数定义。若经常甚至每一步都有反馈，通常称为稠密奖励；若只在成功、失败等少数事件出现明显反馈，通常称为稀疏奖励。稀疏并不必然等于只在回合结束给奖励，中途事件也可以触发。PPO 和 DQN 都能使用这两类任务，算法名称不决定奖励是否稀疏。

因此，“这一局没结束就拿不到回报”需要拆开看：每次 step 已产生的奖励马上可见；已收集片段的累计奖励也可以立即计算并用于学习；还未知的只是这段记录之后尚未发生的结果。任务没有结束，不意味着目前没有任何反馈或不能训练。

奖励与回报有联系，但不等同：奖励是环境某一步给出的反馈；回报是从某个时刻开始，把此后奖励按约定的折扣累计得到的量。在一步就结束的任务中，两者可数值相同；多步任务通常不同。Critic 预测的是后续回报，不只是下一次立即奖励。

若“阶段性回报”指一段已观察奖励的累计，它是有效数据。但把该片段的累计值当作从片段起点往后全部收益，相当于忽略窗口以外的后果。已知片段与尚未观察的尾部应区分：使用前者，再按任务边界决定后者是零、需要价值预测，还是等待更多记录。

“阶段性奖励”则属于奖励规则，可以在中途达成子目标或每步推进时给出。添加这种奖励会改变或塑造学习目标，不等于只是把日志分段统计。是否应当添加，需要看任务，而不是为了让 PPO 能开始训练就必须添加。

另一个易混点是“本局到现在总共拿了多少分”与“从当前时刻往后能拿多少分”。前者是已发生的历史累计，后者才是当前状态价值要估计的对象。记录从哪个时刻开始，决定哪些奖励该进入哪一条目标。

## 每一步站在自己的时刻往后看

把第一步的动作前观察和动作保存下来，执行后继续记录后面的奖励。等后续结果出现，就可以为第一步整理“从这一步开始，后来实际获得了什么”。对第二步、第三步也作同样处理，各自只看从自身开始的后续奖励。

| 正在评价哪个动作 | 使用哪些奖励作为后续结果的依据 |
| --- | --- |
| 第一步 | 第一步、第二步、第三步的奖励 |
| 第二步 | 第二步、第三步的奖励 |
| 第三步 | 第三步的奖励 |

这个“从当前一步开始往后的累计奖励”就是回报。这里先不讨论折扣，重点是时间归属：过去已发生的奖励不算在当前动作的后续结果中；当前动作执行后立刻收到的奖励则要包含。

在仅终点给奖励的例子里，最后的成功奖励会进入前面各步的回报。不是把这一份奖励平均分给三个动作，也没有把环境真的发出的总奖励增加三份；而是分别为三个不同时刻构造“从这里往后”的评价依据。

## 折扣规定怎样重视较远的奖励

将后续奖励纳入回报后，还需要规定这些奖励的权重。折扣回答的是：一份奖励离当前动作越远，在评价当前动作时还占多少分量。它不改变环境真的发出多少奖励，也不是 Actor 的抽样概率。

沿用到达安全区域的任务。假设两条路线最终获得相同奖励，途中没有其他奖励，区别只是到达时间不同。如果完全不打折，这两条确定成功的路线从起点得到相同回报；若对较晚的奖励打折，更早到达的路线会得到较高的折扣回报。这是我们定义的时间偏好，不是环境把晚到的奖励扣掉了。

通常用折扣因子 γ（gamma）控制这种权重：每隔一个决策步，后续奖励就再乘一次 γ。当 γ 小于 1，距离当前越远，权重逐渐衰减；γ 越接近 1，远期结果保留得越多。在已经结束的有限回合中，γ=1 表示不打折；γ=0 只保留当前一步奖励。

γ 是任务与训练设计的一项设置，不是 Critic 猜出来的成功概率，也不是学习率。学习率决定参数每次怎样迈步，折扣决定学习目标怎样重视未来。改变 γ 会改变算法所追求的回报，不能把它仅当成加快训练的旋钮。

折扣过小，延迟的成功奖励对早期动作的影响会很弱，可能不利于学习需要先付出代价的行为；折扣更接近 1 会保留较远结果，但也意味着评价更依赖长时间后的结果与估计，不能断言越大越好。无限持续任务还需处理回报是否有界的问题，不能无条件把有限回合的 γ=1 推广过去。

折扣通常按决策步计算，不是天然按秒计算。环境一步代表多长时间，会影响相同 γ 对实际远近的含义。这里先理解用途，不修改已有任务配置、不推荐具体超参数。

这与已学 DQN 中的 γ 是同一个概念：DQN 的未来 Q 估计需要折扣，PPO 的回报和相关价值学习也需要采用一致的时间定义。本段不重新做算术；按需查阅 [[概念/奖励回报与折扣]] 的机制例子。

## 为什么从最后一步往前整理回报

一段完整经历已经结束后，各时刻的实际奖励都已记录。整理每步回报时，可以复用后面一步已经整理好的结果：当前回报由“本步奖励”和“从下一步开始的回报”组成，后者距离当前多一个决策步，因此整体再乘一次折扣。

```text
当前这一步的回报 = 本步奖励 + γ × 下一步开始的回报
```

本步奖励来自执行本步动作后的环境反馈；下一步回报来自这条经历后半段的已记录奖励，不是随意指定的目标，也不是本段调用 Critic 得到的预测。它内部已经包含更晚奖励应有的折扣，向前接一步时再整体打一次折即可。

自然终止后没有这局的后续收益，可从“终止后的回报为 0”开始。最后一个动作的回报就是它执行后得到的奖励；倒数第二步在自己的奖励上加折扣后的最后一步回报；再继续往前，直到起点。终止后的回报为零，不表示最后一个动作的奖励也为零。

这种从后往前的整理称为倒序递推：先解决后面的部分，再把结果接到前面。它不是让环境倒着运行，也不是神经网络的反向传播；本段没有修改网络参数。实际交互仍按时间向前发生，只有事后数据整理采用倒序。

这样不会把已经过去的得分算成当前动作的后果，也不用对每一步重新遍历整段未来。整理完后，每条原来的动作前观察和动作，都能对应自身时刻的回报，顺序仍要匹配，不能因为倒序计算而把回报顺序反着交给网络。

这个边界依赖“任务真正结束”。如果只是采样记录到这里，环境中的回合仍在继续，后续回报不能自动视为零，需要按下面的方式补充估计。

## 只收集到半途时，怎样补上未看到的未来

PPO 常按固定步数收集一批经历，便于统一组织训练。无论奖励稀疏还是稠密，已收集片段都可以用于学习，不要求等待整局结束。假设游戏还在进行，角色也没有失败，但本轮已经收集够数据，要先进行更新。停止的是采样，不是游戏任务；若此时把未观察到的尾部设为零，就把“暂时没看到”错误地当成了“以后没有”。已看到的阶段性奖励并没有被丢弃。

仍用“到达安全区才得到奖励”的任务说明：一段正确的移动过程可能尚未走到安全区。如果仅因采样窗口在这里结束就舍弃所有后续收益，这段记录的目标会漏掉可能到来的成功奖励，并引入人为采样边界造成的低估。

此时把最后一个已执行动作之后得到的观察交给 Critic，请它估计从这个接续位置出发的后续回报。这个值用作倒序整理的起点，再逐步接上已记录的奖励和折扣。用的是末动作之后的观察，不是末动作之前的观察，也不是 reset 后新一局的起点。

```text
片段最后一步的目标
= 这一步实际奖励 + γ × Critic 对下一观察的回报估计
```

因此，“与真实奖励结合”这个方向正确，准确对象是 Critic 的预测值：把片段内已收到的奖励，与 Critic 对片段之后的回报预测按时间折扣接起来，而不是把两者任意平均。Critic 在这一处补充的是未见未来，不应使用动作前的当前价值来重复覆盖已经计入的奖励。

之前的递推关系没有变，只是“下一步开始的回报”尚未完整观察到，用一个价值预测代替。片段中的实际奖励保持原样；终点处的估计只补未观察到的后续部分，不与同一部分已经计入的奖励重复相加。

这种用价值估计接上未观察未来的办法通常称为自举（bootstrap）。DQN 用下一状态的 Q 估计构造目标，也是这一思想；这里用状态价值预测而非对动作 Q 值取最大。

| 片段为什么停止 | 尾部怎样处理 |
| --- | --- |
| 任务真正终止，成功或失败结束本局 | 本局之后的回报为 0，最后一步奖励仍保留 |
| 只是本批采样够了，任务仍可继续 | 用接续观察的价值估计补上后续回报 |

接了价值预测的结果是学习目标或回报估计，不再是完全由这次真实经历相加得到的完整回报。Critic 可能不准，误差会影响目标；后续新经历为继续纠正预测提供依据，不保证立刻准确。构造本批目标时把这个尾部估计视为固定依据，不要求梯度穿过它来反向修改自己的目标。

上述只是回报与片段边界的基础关系，不是宣称完整 PPO 的价值目标只采用这一种递推；后续优势估计会沿同样的“真实奖励加尾部估计”思想展开。环境报告的时间上限还需要按任务定义判断，不能把所有停止都笼统归到同一种边界。

## 目标也用了预测，为什么还能学得更准

Critic 不是单纯拿自己的旧答案当正确答案。当前观察的预测，要与“实际发生的奖励，加上下一观察的未来预测”对照。两个预测对应不同时间位置，中间还接入了环境提供的新事实。

例如角色经过 A、B、C 到达终点，只有到达终点才得到成功奖励。实际走完 C 到终点这一步后，C 的目标直接由真实奖励确定，终止后没有尾部预测。随着 C 的价值估计改善，B 到 C 的记录就能借助 C 的估计改善 B 的目标；A 也能通过 B 得到更有依据的目标。这说明真实反馈如何影响较早位置，不要求程序严格按 C、B、A 顺序训练，也不表示 PPO 必须只用单步目标；同一片段内的多步奖励可以直接提供更远的实际依据。

Critic 一开始的预测确实可能不准，尾部误差也会进入目标。持续收集经历会让先前未看到的后果变成实际反馈，从而提供纠正依据。但在稀疏奖励任务中，如果策略始终没有遇到成功奖励，预测并不能凭空告诉它成功在哪里；仍需要探索得到有信息的经历。

这里与 DQN 的联系是“利用真实奖励修正对未来的估计”。区别在于 DQN 的 Q 预测针对状态与动作，PPO 的 Critic 通常预测从当前观察出发、按当前策略继续行动的回报。以上解释的是学习依据如何形成，尚未进入损失和参数更新实现。

## 回报提供线索，不是对每个动作的正确性证明

同一段成功经历中的动作可能既有有效选择，也有绕路或被后续动作补救的失误。最终成功不能证明每一步都是最佳选择。用后续回报，是把影响延迟的反馈带回来；要判断一个动作相对当前策略是否更好，还需要结合当时的价值预期以及更多经历。

因此 Critic 在三个时刻可以给出不同预期，即使后续收到同一个终点奖励，各步的相对评价也不一定相同。不能把整段经历的总分复制成每一步相同的优势，更不能据此给所有动作相同的更新。

## DQN 也能利用延迟奖励

不能把“后续结果影响早期动作”理解为 PPO 独有的能力。基础 DQN 的单步目标就包含当前奖励与下一状态的未来 Q 估计，因此当前即时奖励为零，也不等于学习目标为零。

在三步后才获奖的例子里，靠近奖励的动作先可从实际奖励改善估计，更早一步的更新再利用下一状态的收益估计。通过反复学习和目标网络同步，未来收益能够向前面的状态动作传播。这是信息依赖的解释，不要求实际程序严格倒序更新，也不保证神经网络总能学好。

与本课连续奖励最直接对应的改进是 [[概念/多步回报与n-stepDQN|n-step DQN]]：一次目标直接纳入连续 n 步实际奖励，再在片段未自然终止时接上片段末尾的未来 Q 估计。真实奖励按时间折扣；片段必须来自连续经历，不能把随机抽出的无关转移拼起来。这样较晚的奖励能更直接进入较早动作的目标，但 n 更大不保证更好。

Rainbow 将多步学习与其他 DQN 改进组合使用。机制可核对 [Rainbow 原论文的 DQN 背景与多步学习部分](https://arxiv.org/html/1710.02298v1)。本段用于连接已有知识：利用多步奖励不等于采用 PPO 的 Actor 或裁剪更新；DQN 主线继续暂停，不因这次对照启动支线实作。

## 接到 PPO 的学习流程

收集时记录观察、动作和逐步奖励；整理数据时保持轨迹顺序，为各个时刻构造后续收益依据；然后结合价值估计形成策略学习所需的评价。它们不在同一个时刻产生：动作前能获得观察和预测，实际后续奖励只有环境推进后才可获得。

完整回合用实际后续奖励，未结束的片段需要价值估计补充尾部；两者的证据来源不同。整理每步目标时保持观察、动作与时间对应，不能把新回合的奖励接到旧回合后面。

现在可以把收益依据接回 Actor 的评价。动作前，Critic 对当前观察给出“按当前策略继续，通常能获得多少回报”的基准；动作执行后，本步真实奖励与下一观察的价值预测提供新的收益依据。用后者减去动作前的基准，就得到一次“结果比原来预期好还是差”的比较。

```text
单步评价信号
= 本步真实奖励 + γ × 下一观察的价值预测 − 当前观察的价值预测
```

下一观察的预测补未见未来，当前观察的预测提供比较基准，两者职责不同。这个差值通常称为时序差分误差，可以作为单步优势估计；实际 PPO 常把多步这样的信号结合起来构造优势，不能将单步关系等同于所有 PPO 实现。

正的评价信号为 Actor 增加该观察下已采样动作的倾向提供依据，负的则提供减小倾向的依据。得到正奖励仍可能低于原预期，没有立即奖励也可能因进入更有前景的位置而高于预期。一次结果受环境随机性与预测误差影响，不是对动作好坏的最终证明。

同一批经历也为 Critic 改善回报预测提供目标。通常先用更新前的价值预测整理并固定本批目标与优势，再分别训练 Actor 和 Critic；不是先让 Critic 拟合这一条结果，再拿拟合后的值作为这条动作的原预期。这里建立评价依据的连接，不展开损失和参数更新实现。

## 多看几步，改变了评价的哪些依据

单步评价在执行一个动作后，就用下一观察的价值预测补上剩余未来。若已连续记录后面几步，可以用这些真实奖励替代对应时段的预测，再在更远的片段末尾接上价值估计。这里改变的是评价时使用的证据长度，不是让 Actor 一次输出多个动作。

例如角色绕过障碍后到达目标。只看第一次移动，可能尚未收到奖励，对后续收益的判断主要来自 Critic；看完连续几步后，实际到达目标的奖励就可以直接进入最初动作的评价。不再需要 Critic 猜测这段已经观察到的结果。

评价同一个起点动作时，一步、两步或更长片段都减去该起点的同一个价值基准。它们区别在于用了多长的实际经历，以及从哪里开始用预测补尾部；奖励和尾部预测仍按各自时间距离折扣。若中途任务真正终止，尾部为零，不能继续接新一局。

看得更远并不必然评价更准。它减少了对近处尾部预测的依赖，但会纳入更多后续动作抽样和环境随机变化。因此同一个起点动作的一次长期结果可能很好，另一次却很差，不能把单次后果完全归因于最初动作。看得较近通常能减少这类波动，却更依赖 Critic 的准确性。

PPO 常用的优势估计会结合不同长度的评价，在预测误差与采样结果的波动之间取舍。它利用同一批连续记录，不需要为每一种长度重新行动一次。

## GAE 怎样结合不同长度的评价

GAE（广义优势估计）是一种计算优势的方法。它读取已采集的奖励、价值预测和轨迹边界，为每个已采样动作整理一个优势估计，不需要再增加一个神经网络。它将同一起点的一步、两步及更长评价按权重组合；这些评价都使用同一个起点基准，不是把不同动作的最终优势随意平均。

控制这种组合的参数是 λ（lambda），通常在 0 到 1 之间。λ 为 0 时只保留单步评价；增大 λ 会让较长经历的评价占据更多权重，减少对近处尾部预测的依赖，同时通常带来更多采样波动。λ 为 1 时利用当前连续片段直到边界的奖励：若真正终止，就得到完整折扣回报减起点价值；若只到采样窗口末尾，仍需末状态价值补尾部。它不意味着等待整局结束，也不意味着不再需要 Critic。

γ 和 λ 作用不同。本课的 γ 定义回报中远期奖励的折扣；λ 控制如何利用不同长度的经历估计这个回报对应的优势。λ 为 0 不等于只追求即时奖励，因为单步评价里仍有 Critic 对未来的预测。这里不设置具体数值，也不将较大 λ 视为必然更好。

实际计算不必为每种长度分别遍历整段奖励。前面已得到每一步的“本步奖励加下一价值，再减当前价值”，也就是时序差分误差。它表示走过这一步后，对原来收益预期出现了多少修正。GAE 可以等价地把同一条轨迹中这些逐步修正按距离衰减后相加。

例如走向出口的第一步没有奖励，Critic 也没有预见成功，单步误差可能很小；后面真实到达出口时，如果成功奖励超出了当时的预测，就产生正的误差。GAE 让这份后面才出现的修正也影响前面动作的评价。若成功本就在预测之内，末步误差可能很小；并不是每次收到正奖励都要再额外给前面动作加一遍分。

若下一步开始的修正已经汇总成了 GAE 优势，当前一步就可以复用它：

```text
当前优势估计
= 当前一步的时序差分误差 + γ × λ × 下一步的优势估计
```

下一步的优势在这里是后续误差的汇总，不是 Critic 直接输出的价值。γ 处理时间折扣，λ 控制后续修正继续向前传递的权重。因此可以从片段末尾向前整理。这与“结合不同长度的评价”是同一 GAE 的两种等价写法，不是额外再平均一次；当前只理解关系，不要求手算或编程。

在记录末尾，没有更多已记录误差可汇总，递推的尾部优势置零；但若任务仍在继续，最后一步误差中的下一状态价值仍需保留。尾部优势为零不等于未来价值为零。真正终止时则同时停止跨回合的误差传递，并令终止后的价值为零。所有误差均由本批固定的价值预测整理，不是在倒序计算中反复更新 Critic。

结合方法与端点定义可查 [GAE 原论文第 3 节](https://arxiv.org/html/1506.02438v6#S3)。递推的代码实现留到后续实作阶段。

## 同一份评价怎样分别用于 Actor 和 Critic

整理出 GAE 优势后，还要区分两个训练问题。Actor 要知道已采样动作比当前策略通常水平好多少，优势正好提供这个相对评价；Critic 则要预测从当前观察出发的回报，不能直接把优势当作回报来拟合。

采用 GAE 的一种常见实现会将原始优势加回同一观察的旧价值预测，得到 Critic 的回报目标：

```text
Critic 的回报目标 = 本批原始 GAE 优势 + 采样时保存的当前观察价值
```

减去价值基准，是为了给 Actor 一个相对比较；加回基准，则将评价还原到回报的尺度，让 Critic 有可拟合的目标。GAE 优势已经包含奖励和未来预测提供的修正，并非将旧预测原样当成答案。该目标一般仍是估计值，不应称为全部实际观测的完整回报。

本批优势与目标先固定，再用于更新。Actor 利用优势构造策略学习目标；Critic 用更新过程中的新预测与固定回报目标比较。不能每次拿刚更新的价值重新加回同一份旧优势，让目标跟着预测一起移动。这里使用的是原始 GAE 优势；后续如果为了策略训练对优势做标准化，不能把标准化后的优势加到价值上构造回报目标。

这一目标构造可在 [Stable-Baselines3 的 RolloutBuffer 源码](https://raw.githubusercontent.com/DLR-RM/stable-baselines3/master/stable_baselines3/common/buffers.py) 中核对。

## Critic 的目标怎样变成参数变化

固定回报目标只是学习依据，保存目标或算出误差都不会自动改变网络。训练时，先把记录中的观察重新交给当前 Critic 做前向计算，得到依赖当前参数的新预测。这个预测参与梯度计算；用于构造本批目标的旧价值则是固定数据。即使第一轮两者数值相同，计算职责也不同。

最基本的价值损失是预测与目标之差的平方，并对一批样本取平均。平方使正负误差不能互相抵消，预测偏离目标越大，惩罚越大。这与 DQN 拟合 Q 目标的学习机制相通，只是这里拟合当前策略的状态价值。具体实现还可能使用价值裁剪等设置，本段先看基本关系。

```text
观察 → 当前 Critic 的预测 → 与固定回报目标比较 → 损失
```

在 PyTorch 的梯度追踪开启时，前向运算会保留依赖关系，形成计算图：预测依赖各层参数，损失又依赖预测。因此 loss 虽然刚创建，仍能沿这些关系追溯到参数。固定目标不参与这条求梯度路径；计算图也不是“把环境历史倒放”。

执行 backward() 时，框架沿计算图计算损失对各参数的梯度，写入参数的 .grad；这一步通常还没改参数。optimizer 事先持有要训练的参数，执行 step() 时读取这些参数的梯度，并结合学习率和自身状态修改参数，所以不需要再绑定某个 loss。独立更新前通常先清除上一轮梯度，避免无意累积。

下一次前向计算才使用新参数，产生新的预测。优化不是直接把某个输出改成目标，也不能把“预测偏低”理解为所有权重一起增大；不同参数的作用由梯度区分，同一批样本还共同影响共享权重。因此单次更新不保证每条预测都改善，更不保证策略已变好。本段为已有训练机制的概念连接，没有实现或运行更新，也不算学习者完成训练。

## Actor 怎样把优势变成动作倾向的变化

Actor 没有“正确动作概率”可直接照着拟合。经历只告诉我们某次已采样选择相对预期的好坏，优势也不是一个目标概率。因此要设计一个损失，让增加正优势动作的概率、降低负优势动作的概率成为有利的优化方向。

更新时，把记录中的同一观察交给当前 Actor，取出当时实际采样动作的当前概率，不重新抽动作。再用它除以采样时保存的旧概率，得到概率比。分母与本批优势固定，分子随当前 Actor 参数变化。为看清方向，先看尚未触发裁剪的单条损失：

```text
策略损失 = −概率比 × 优势
```

优势为正时，增加当前概率会使这个损失更小；优势为负时，降低当前概率会使损失更小。负号来自优化器通常最小化损失的约定。Actor 不拟合优势数值，也没有将环境奖励当作可修改的参数。完整 PPO 会使用 [[课程/200-policy-feedback#裁剪公式为什么要取较小值|200 已解释的裁剪目标]] 限制继续向有利方向推远的收益，而不是无限优化这里的简式。

梯度路径从策略损失经过概率比、当前动作概率，回到 Actor 参数。优势虽然来自奖励和 Critic 预测，本批计算中作为固定评价使用；这条路径不穿过已经发生的动作抽样或环境，也不通过调整 Critic 来改变评价。如果错误地只使用保存的旧概率构造损失，就没有当前 Actor 的前向计算可追溯，不能形成所需的策略梯度。

随后 backward() 将梯度写入相应参数的 .grad，optimizer.step() 读取梯度修改参数；下一次 Actor 前向计算才使用新参数。多个动作的概率受同一分布与共享参数约束，不是单独改一个数字而其余全不变。若网络共享部分结构，参数影响范围由实际结构决定；这里区分的是两种损失的职责，不要求一定有两个优化器。当前仍是机制讲解，没有启动训练。
