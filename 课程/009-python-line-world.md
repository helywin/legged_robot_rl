# 纯 Python 走格子环境

## 为什么先学它

机器狗同时涉及关节、物理仿真和神经网络，容易遮住最基本的强化学习循环。这里先用一条只有 5 个格子的直线：

```text
[A][ ][ ][ ][G]
```

- `A` 是当前位置；
- `G` 是目标；
- 观察是当前位置数字；
- 动作只有向左、向右；
- 到达目标奖励 `+1`；
- 没到目标的每个 step 奖励 `-0.01`；
- 到达目标或用完 10 个 step，episode 结束。

## 两个策略

程序提供两个策略：

- `right`：人写死每次向右，属于手写策略，并没有学习；
- `random`：每次随机选择向左或向右，也没有学习。

先比较这两个策略，是为了看懂环境如何运行。真正“从反馈中学习”的策略放到下一步。

## 运行命令

```bash
.venv/bin/python -m examples.line_world --policy right
.venv/bin/python -m examples.line_world --policy random --seed 0
```

## 运行记录

- Python 依赖：仅标准库
- 实际解释器：Python 3.14.6
- 代码位置：`examples/line_world.py`
- 测试位置：`tests/test_line_world.py`
- 单元测试：3 项全部通过
- `right` 手写策略：4 个 step 到达目标，总奖励 `+0.97`
- `random --seed 0` 随机策略：6 个 step 碰巧到达目标，总奖励 `+0.95`

这次只完成了 Python 环境运行和两个非学习策略的对比，尚未实现任何强化学习算法。

## 观察问题

1. `position` 对应之前学过的哪个概念？
2. `left/right` 对应哪个概念？
3. `right` 策略能够到达目标，是否说明它经过了强化学习？为什么？
4. 随机策略某次碰巧到达目标，是否说明它已经学会？为什么？

## 第一组答题记录

- 第 1 题：正确，`position` 是观察。
- 第 2 题：正确，`left/right` 是动作。
- 第 3 题：正确，`right` 是人写死的固定策略，没有通过反馈学习。
- 第 4 题：正确，随机策略碰巧成功不代表学会；它没有利用这次奖励改变以后选择动作的方式。

## 结果分析题

1. `right` 本次总奖励是 `+0.97`，随机策略本次是 `+0.95`。只比较这一个 episode，就能可靠断定 `right` 在所有运行中都更好吗？为什么？
2. 为什么每个未到目标的 step 都给 `-0.01`，会鼓励策略更快到达目标？
3. 当前位置是 `0`，策略选择 `left`，因为已经在最左边，所以新位置仍是 `0`，并得到 `-0.01`。请分别指出：旧观察、动作、新观察和奖励。
4. 如果删掉每步的 `-0.01`，只在到达目标时给 `+1`，那么 4 步到达和 9 步到达在本环境中得到的总奖励是否一样？这可能让策略缺少什么动力？

## 第二组答题记录

- 第 1 题：结论“不能”正确，但理由需要修正。关键不是 `right` 是固定策略，而是随机策略只运行一个 episode 时，结果可能受偶然动作序列影响。
- 第 2 题：正确。更快到达会少承受几次 `-0.01`，所以总奖励更高。
- 第 3 题：旧观察 `0`、动作 `left`、奖励 `-0.01` 正确；新观察应是 `0`，不是 `-1`，因为环境不允许越过左边界。
- 第 4 题：正确。两条路径都会得到 `+1`，策略缺少尽快到达目标的动力。

## 多次运行的实际结果

为检查单次随机成功是否可靠，实际运行了更多 episode：

- `random` 策略使用随机种子 `0～9`：2 次到达目标，8 次步数用完；
- `right` 策略使用随机种子 `0、1、2`：3 次都在 4 个 step 到达，总奖励均为 `+0.97`。

`right` 函数完全忽略随机数，所以在这个确定性的走格子环境里结果相同。随机策略的结果会随动作序列变化，这正说明不能用一次碰巧成功判断它已经学会。

## 纠正题

1. 再填一次：旧位置为 `0`，执行 `left` 后，旧观察、动作、新观察、奖励分别是什么？
2. 随机种子 `0` 时随机策略成功了，但 10 次中只有 2 次成功。为什么这组结果更能说明它没有稳定学会？

## 本课结论

- 位置 `0` 执行 `left` 后仍停在 `0`，因为状态变化由环境规则限制；
- 一次随机成功不能证明学习，必须观察多次运行是否稳定；
- 当前两个策略都不会根据奖励改变，因此尚未发生强化学习。
