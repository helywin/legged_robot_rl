# 为什么 Q 值要考虑下一位置

## 只看眼前奖励会有什么问题

在走格子环境中，从位置 2 向右走到位置 3：

```text
位置 2 --right / reward=-0.01--> 位置 3 --right / reward=+1.00--> 终点
```

位置 2 的 `right` 动作眼前只得到 `-0.01`，但它把小人带到接近终点的位置 3。如果只用即时奖励评价它，就会忽略这个动作带来的未来机会。

因此，更新当前 Q 值时，参考目标应该包括两部分：

```text
当前一步的奖励 + 下一位置最好的已知价值
```

## 为什么看下一位置最高的 Q 值

假设位置 3 当前有两个动作：

| 下一位置 | `left` | `right` |
| --- | ---: | ---: |
| 位置 3 | `0.20` | `0.80` |

到了位置 3 后，策略可以选择当前看起来更好的 `right`。因此估计位置 2 的 `right` 时，参考的是下一行中最大的 Q 值 `0.80`，而不是较差动作的 `0.20`。

> [!note] 这不是同时更新两个格子
> 本次仍然只更新 `Q(位置2, right)`。`Q(位置3, right)=0.80` 只是用来帮助判断前一个动作有多值得。

## 折扣因子

未来价值通常不会原封不动地加进来，而是先乘一个 **折扣因子**。它表示当前判断有多重视未来，常用 `gamma` 表示。

| 折扣因子 | 含义 |
| ---: | --- |
| `0` | 完全不考虑未来，只看当前奖励 |
| 接近 `1` | 很重视未来价值 |

假设：

- 当前奖励是 `-0.01`；
- 下一位置最高 Q 值是 `0.80`；
- 折扣因子是 `0.90`。

先用普通话概括：

> 这次要参考的目标 = 当前奖励 + 打过折扣的下一位置价值

再写成计算：

```text
目标值 = -0.01 + 0.90 × 0.80
       = 0.71
```

这里算出的 `0.71` 是这次学习应该参考的**目标值**，还没有使用学习率去修改旧 Q 值。下一课才把两个步骤合起来。

## 到达终点时

如果当前动作执行后已经到达终点，就没有下一位置的未来动作需要考虑。此时目标值只使用当前得到的终点奖励。

## 思考题

1. 从位置 2 向右只得到 `-0.01`，但下一步就可能到终点。为什么不能只用 `-0.01` 评价这个动作？
2. 下一位置的 Q 值是 `left=0.20`、`right=0.80`，计算未来价值时应该参考哪个值？为什么？
3. 折扣因子为 `0` 和接近 `1` 时，分别更看重眼前还是未来？
4. 当前奖励为 `-0.01`、下一位置最高 Q 值为 `0.80`、折扣因子为 `0.90`，目标值是多少？

## 回答记录

1. 不能只看当前的 `-0.01`，因为这个动作带来的后续价值更高。
2. 应参考下一位置的 `right=0.80`，因为它是当前已知的最佳未来收益。
3. 折扣因子为 `0` 时只看眼前；接近 `1` 时更看重未来。
4. 目标值是 `-0.01+0.90×0.80=0.71`。

> [!success] 本课结论
> 非终点动作的学习目标既包含当前奖励，也包含打过折扣的下一位置最佳 Q 值。
