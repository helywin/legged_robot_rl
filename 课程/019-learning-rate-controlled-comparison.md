# 只改变学习率的对照实验

## 本课问题

上一课中的 ε 控制“怎样选择动作”。本课只改变学习率，观察它控制“取得一次经验后，Q 值改变多大一步”。

```text
ε：决定是否随机探索
学习率：决定一次经验让 Q 值改变多少
```

## 实验设计

为了让学习速度的差异仍然可见，只训练 20 个 episode：

| 条件 | 设置 |
| --- | --- |
| 环境 | 同一个五格走格子环境 |
| 训练轮数 | `20` |
| ε | `0.20` |
| 折扣因子 | `0.90` |
| 随机种子 | `0` |
| 评估 | 关闭探索、停止更新，运行 10 轮 |
| 唯一变量 | 学习率 `0`、`0.05`、`0.20`、`1.0` |

如果仍训练 500 轮，多组Q表可能都已经非常接近最终值，不容易观察更新速度差异。

## 实际结果

| 学习率 | 训练成功 | 位置0-`right` | 位置3-`right` | 评估成功率 |
| ---: | ---: | ---: | ---: | ---: |
| `0` | 4/20 | 0.000 | 0.000 | 0/10 |
| `0.05` | 18/20 | 0.005 | 0.603 | 10/10 |
| `0.20` | 18/20 | 0.372 | 0.982 | 10/10 |
| `1.0` | 14/20 | 0.702 | 1.000 | 10/10 |

## 学习率为 0 为什么不能学习

学习率为 `0` 时：

```text
新 Q 值 = 旧 Q 值 + 0 × 差距
         = 旧 Q 值
```

训练中4次到达终点只是探索和并列随机造成的行为成功，Q表仍然全为零，没有保存这些经验。评估函数在全零并列时固定取第一列`left`，所以最终0/10。

这再次说明：训练中偶然到达目标，不等于策略已经学会。

## 学习率怎样改变更新速度

20轮后，最靠近终点的`Q(位置3,right)`是：

```text
学习率 0.05 → 0.603
学习率 0.20 → 0.982
学习率 1.00 → 1.000
```

当前环境中，位置3向右的结果始终是终点奖励`1.0`。学习率越大，每次朝`1.0`移动越远，因此更快接近它。

## 为什么不能说越大永远越好

当前环境的奖励和位置转移几乎固定，学习率`1.0`会很快得到正确结果。但如果同一个动作有时幸运、有时倒霉，学习率`1.0`会完全采用最近一次结果，Q值可能来回跳动。

> [!warning] 结论边界
> 本实验说明学习率在当前固定玩具环境中怎样影响更新速度，不能证明`1.0`是复杂或有噪声任务的最佳学习率。只使用了一个随机种子，也不能比较统计稳定性。

## 训练成功次数为什么不按学习率排列

20轮训练期间仍使用`ε=0.2`，其中包含随机探索；不同Q值又会改变利用动作。因此14/20或18/20不是学习率大小的直接刻度。是否学到可用策略仍以关闭探索后的评估和Q表为主要依据。

## 思考题

以下问题都基于本课表格中的20轮实验：

1. 学习率为`0`时，训练中为什么还能到达目标4次？这说明Q表学会了吗？
2. 学习率从`0.05`增加到`0.20`后，位置3的`right`从`0.603`变成`0.982`。这反映学习率控制什么？
3. 学习率与ε分别控制什么？如果只想研究学习率，为什么ε必须保持不变？
4. 当前固定环境中学习率`1.0`表现很好，为什么不能直接断定机器狗训练也应该使用`1.0`？

## 回答记录

1. 学习率为0时，4次成功来自随机探索，并不代表学会；位置3的`right`仍为0，说明Q表没有保存成功经验。
2. 学习率控制Q值朝目标值移动的速度和单次变化幅度。
3. ε控制随机探索概率，学习率控制Q值更新幅度。研究学习率时必须固定ε，否则随机探索次数变化也会影响训练结果。
4. 复杂环境中的经验可能有噪声；学习率为1会让单次经验完全覆盖旧判断，容易造成Q值震荡或大幅波动。四题均回答正确。

> [!success] 本课结论
> 学习率不决定选择哪个动作，而决定一次经验让Q值朝目标移动多大一步；训练中偶然成功也不等于Q表已经保存经验。
