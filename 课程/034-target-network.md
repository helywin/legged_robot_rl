# 目标网络：暂时固定训练目标

## 本课目标

长期方向仍是 DQN 游戏和 Go2 强化学习。本课只理解：**为什么 DQN 用一份暂时固定的参数计算目标 Q 值，而不是让同一组正在更新的参数同时决定预测和目标。**

## 移动的答案

上一课已经知道，参数会根据误差更新：

```text
目标 Q 值 - 当前预测 Q 值 → 误差 → 更新参数
```

但非终止经验的目标 Q 值又要参考下一观察的 Q 值。如果也使用刚刚更新的同一组参数计算未来价值，那么参数变化时，当前预测和训练目标会同时变化，像一边答题一边改答案。

目标网络提供一份暂时不动的参数副本，让训练目标在若干次更新内保持稳定。

## 两份参数的职责

本课只引入两个名称：

- **在线网络**：正在学习的那份参数，负责当前预测，每次训练更新它；
- **目标网络**：在线网络的旧副本，只用于计算目标 Q 值，若干次更新内保持不变。

流程是：

```text
当前观察 ─→ 在线网络 ─→ 所选动作的预测 Q 值

下一观察 ─→ 目标网络 ─→ 未来 Q 值 ─→ 目标 Q 值

预测与目标形成误差 ─→ 只更新在线网络

经过固定次数 ─→ 把在线参数复制给目标网络
```

最后一步叫**同步**。同步之后，目标网络再次保持固定，直到下次同步。

## 最小受控演示

- 问题：目标参数是否只在同步时改变？
- 固定条件：观察 `1.0`、奖励 `0.2`、折扣因子 `0.9`、学习率 `0.2`；
- 唯一规则：在线参数每步更新，目标参数每 3 步同步一次；
- 成功条件：同步前目标 Q 值保持不变，同步后才改变。

运行：

```bash
.venv/bin/python -m examples.target_network_demo
```

实际输出：

```text
step=1 online=1.000000->1.020000 target=1.000000->1.000000 target_q=1.100000 synced=False
step=2 online=1.020000->1.036000 target=1.000000->1.000000 target_q=1.100000 synced=False
step=3 online=1.036000->1.048800 target=1.000000->1.048800 target_q=1.100000 synced=True
step=4 online=1.048800->1.067824 target=1.048800->1.048800 target_q=1.143920 synced=False
step=5 online=1.067824->1.083043 target=1.048800->1.048800 target_q=1.143920 synced=False
step=6 online=1.083043->1.095219 target=1.048800->1.095219 target_q=1.143920 synced=True
```

第 1～3 步在线参数连续变化，但目标 Q 值保持 `1.100000`。第 3 步同步参数以后，第 4 步目标 Q 值才变成 `1.143920`，达到本演示的成功条件。

## 真正终止时的边界

`terminated=True` 时任务已经真正结束，目标 Q 值只使用本步奖励，不需要读取目标网络的未来价值。目标网络解决的是非终止经验中“未来 Q 值从哪里来”的稳定性问题。

目标网络不会保证训练一定成功，也不会替代经验回放、探索、奖励或评估。它只是减少训练目标随在线参数每一步一起快速变化的问题。

> [!success] 当前证据
> 单参数目标网络示例实际启动成功，新增 6 项测试验证了非终止目标、真正终止、在线参数更新、同步前固定、同步复制和同步后目标变化。它不是真实神经网络或 DQN 训练，也没有验证游戏、Isaac Lab、仿真机器人或真机。

## 一句话总结

目标网络是在线网络的一份暂时固定副本，用它计算未来 Q 值，并定期从在线网络同步参数。
