# 第六课：交互步

## Step 不是迈出一只脚

强化学习中的 **step（交互步）**，不是指机器狗向前迈了一只脚，而是指完成一次最小交互循环。

一次 step 包括：

1. 机器狗得到当前观察；
2. 策略根据观察选择动作；
3. 环境执行这个动作并计算变化；
4. 环境返回新的观察和奖励。

```text
当前观察 → 策略 → 动作 → 环境 → 新观察和奖励
|___________________________________________|
                  一个 step
```

一秒钟内通常会连续发生很多个 step。机器狗正是通过快速重复这个循环，持续调整身体。

## 一个小问题

机器狗完成“得到观察、选择动作、环境计算、收到新观察和奖励”这一整次循环，叫作什么？
