# 训练与评估

训练阶段允许探索并更新参数；评估阶段使用冻结后的策略，不探索、不更新，只测量它实际能否完成任务。

训练期间偶尔成功不能证明策略稳定，评估也不能反过来继续修改用于被测的 Q 表或模型。
