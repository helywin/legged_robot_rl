# 策略动作到关节控制

读四足代码时，先回答“策略输出的这个数，究竟让谁去做什么”。策略动作、目标角度、关节力矩是不同环节。本页用单个关节说明一种常见连接；所有数值均为教学假设，不是 Go2 或目标仓库的实际参数。

## 从 0.4 到 0.9 弧度

假设接口把策略输出解释成相对默认姿态的角度偏移：

| 量 | 数值与单位 | 从哪里来 |
| --- | --- | --- |
| 策略动作 a | 0.4，无量纲 | 策略前向输出，假设已通过动作限幅 |
| 默认角度 q_default | 0.8 rad | 任务配置 |
| 动作缩放 scale | 0.25 rad / 动作单位 | 任务配置 |

先缩放，再加默认角度：

```text
角度偏移 = 0.25 × 0.4 = 0.1 rad
目标角度 q_des = 0.8 + 0.1 = 0.9 rad
```

这一步只是生成目标。真实关节不会瞬间跳到 0.9 rad，还要经过执行器和动力学。

## PD 怎样把角度目标变成力矩

**力矩**可以理解为让关节转动的作用。**PD 控制**根据两项误差计算它：P 项按角度差拉向目标，D 项按速度差抑制过快运动。

继续上例，假设当前角度 q = 0.85 rad、角速度 dq = 0.2 rad/s，期望速度为 0。假设 P 增益 Kp = 20 N·m/rad，D 增益 Kd = 0.5 N·m·s/rad：

```text
角度差 = 0.9 - 0.85 = 0.05 rad
P 项 = 20 × 0.05 = 1 N·m
速度差 = 0 - 0.2 = -0.2 rad/s
D 项 = 0.5 × (-0.2) = -0.1 N·m
合计力矩 = 1 - 0.1 = 0.9 N·m
```

对应公式为：

$$
\tau = K_p(q_{des}-q) + K_d(\dot q_{des}-\dot q)
$$

这里 τ 是力矩，带点的 q 表示角速度。上述结果还没包含限幅、摩擦、重力补偿、电机特性和接触等因素。PD 项的基本意义可参考 [MIT Manipulation 的控制说明](https://manipulation.csail.mit.edu/force.html)。

## 两个循环不能混成一个

```text
策略读观察 → 输出动作 → 缩放为目标角度
                          ↓
当前关节角度和速度 → PD 计算 → 执行器与物理仿真推进
                          ↓
                     新状态、奖励
                          ↓
              采集经历后，由学习算法更新策略
```

PD 的角度误差不是强化学习奖励；PD 计算一次，也不等于神经网络做了一次 `backward()`。常规 PPO 训练通过采样数据更新策略，并不因为环境里有 PD，就自动沿整段物理运动求导。

策略还可能每隔数个物理小步才输出一次动作，期间控制器反复跟踪目标。时间含义见 [[概念/动作保持与观察时间对齐]]。

## 用这些边界读实际代码

- 零动作在这个接口里表示默认姿态，不表示零角度或零力矩。沿用当前角度和速度，a = 0 时目标为 0.8，力矩为 20 × (0.8 - 0.85) - 0.5 × 0.2 = -1.1 N·m。
- “期望机身前进 0.5 m/s”可以是策略输入的任务指令，不是上述关节动作。
- 应核对关节顺序、正方向、单位、缩放、限幅以及执行器类型。其他接口也可能直接输出速度或力矩，不能照搬本页解释。

阅读本页只建立控制链直觉；实际仓库的接口、配置与仿真验证按 [[PPO及感知四足课程路线]] 的机器人阶段逐步完成。
