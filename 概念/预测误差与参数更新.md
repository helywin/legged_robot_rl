# 预测误差与参数更新

一条经验直接评价本次所选动作。先按 Q-learning 规则得到目标 Q 值，再计算：

```text
误差 = 目标 Q 值 - 所选动作的预测 Q 值
```

正误差表示预测偏低，负误差表示预测偏高。要知道参数该增大还是减小，还必须看“参数怎样影响预测”；再结合损失与学习率决定更新。

## 与 Q 表更新的关系

```text
Q 表：误差 → 修改一个观察—动作格子
参数估计器：误差 → 修改共享参数 → 多个观察可能受影响
```

目标 Q 值不是即时奖励的同义词；它仍可能包含下一观察的未来价值，并根据 `terminated` 判断任务是否真正结束。

## 预测偏低，为什么权重反而要减小

用一个没有偏置的模型 q = w × x：输入 x = -2，权重 w = -0.5，因此预测 q = 1；目标为 2，预测确实偏低。

平方损失为 (q - 2)²。按链条求导：

```text
目标 - 预测 = 2 - 1 = 1
损失对预测的梯度 = 2 × (1 - 2) = -2
预测对权重的梯度 = x = -2
损失对权重的梯度 = (-2) × (-2) = 4
```

普通 SGD 学习率 0.1：新 w = -0.5 - 0.1 × 4 = -0.9。再预测：q = -0.9 × -2 = 1.8，损失由 1 降到 0.04。

权重变小，预测却变大，因为输入为负。所以“预测偏低就把所有权重调大”会出错。若记差值 δ = 目标 - 预测，平方损失对预测的梯度是 -2δ；差值本身也不等于参数梯度。
