# 预测误差与参数更新

一条经验直接评价本次所选动作。先按 Q-learning 规则得到目标 Q 值，再计算：

```text
误差 = 目标 Q 值 - 所选动作的预测 Q 值
```

正误差表示预测偏低，负误差表示预测偏高。更新使用这个方向和学习率调整共享参数，使下一次预测向目标靠近。

## 与 Q 表更新的关系

```text
Q 表：误差 → 修改一个观察—动作格子
参数估计器：误差 → 修改共享参数 → 多个观察可能受影响
```

目标 Q 值不是即时奖励的同义词；它仍可能包含下一观察的未来价值，并根据 `terminated` 判断任务是否真正结束。

> [!warning] 当前边界
> 当前只验证一个线性参数的误差下降，尚未学习多参数神经网络、反向传播或完整 DQN。

PyTorch 路线已经进一步把职责拆开：[[概念/自动求导与梯度|自动求导]]负责从损失得到梯度，[[概念/优化器与参数更新|优化器]]再使用梯度修改登记参数。

当模型一次输出多个动作 Q 值时，先按实际动作索引得到 [[概念/所选动作Q值与索引|selected_q]]，再用它与目标值计算损失。不能把探索时实际执行的动作替换成当前 `argmax()` 动作。
