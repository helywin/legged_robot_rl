# 多步回报与 n-step DQN

这是可选自学资料。先理解单步目标“本次奖励加下一状态的估计”，再读本篇。

## 为什么多看几步奖励

游戏里，开始移动与随后命中敌机之间可能隔着几次决策。单步更新只直接使用一个奖励，其余效果要依赖下一状态的估计逐步传播。多步回报先收集连续几次真实奖励，再从这一段的末尾接上未来估计。

这样可以让较晚的反馈直接进入较早动作的目标，同时也会引入更多轨迹波动。`n` 越大不一定越好。[Rainbow 原论文的多步学习部分](https://arxiv.org/html/1710.02298v1)

## 同一段轨迹的数字

构造一段三次决策的轨迹，折扣系数为 0.9：

| 时刻 | 执行后的奖励 | 到达的状态 | 该状态用于后续计算的未来估计 |
| --- | --- | --- | --- |
| t | 0 | s1 | 0.5 |
| t+1 | 0 | s2 | 1 |
| t+2 | 2 | s3 | 4 |

三次奖励由环境交互产生；未来估计来自暂时固定的目标计算。先假设整段没有终止。

对最早的动作，单步目标是 `0 + 0.9 × 0.5 = 0.45`。

三步目标逐项算：

1. 第一次奖励不折扣：`0`。
2. 第二次奖励隔一步：`0.9 × 0 = 0`。
3. 第三次奖励隔两步：`0.9² × 2 = 1.62`。
4. s3 的未来估计隔三步：`0.9³ × 4 = 2.916`。
5. 合起来是 `0 + 0 + 1.62 + 2.916 = 4.536`。

这不是把三个独立抽样的奖励相加，而是使用**同一环境、同一回合、时间连续**的一段经验。

用公式记录刚才的规则：

$$
R_t^{(m)}=\sum_{k=0}^{m-1}\gamma^k r_{t+k},\qquad
y_t=R_t^{(m)}+\gamma^m(1-d)Q_{\text{bootstrap}}(s_{t+m})
$$

这里 `m` 是实际收集到的步数，最多为计划的 `n`；`r_t` 指从 t 到 t+1 获得的奖励。`d` 表示这段末尾是否自然终止。bootstrap 的意思是“用当前价值估计接上尚未观察的未来”，可以采用普通 DQN，也可以采用 Double DQN 的选择/估价规则。

## 结束边界怎样算

继续使用上表，分别考虑不同结束原因：

| 情况 | 最早动作的目标 | 原因 |
| --- | --- | --- |
| 第三步后仍继续 | 4.536 | 三步奖励后还有未来估计 |
| 第三步自然终止 | 1.62 | 保留三次奖励，去掉末尾未来项 |
| 第二步被外部采集上限截断，任务允许继续估值 | `0 + 0.9×0 + 0.9²×1 = 0.81` | 只有两步，使用实际末状态 s2；不能仍乘 γ³ |
| 只是读取批次结束，环境未 reset | 可保留尚未凑满的前缀 | 下一批接着同一局收集，不把采样批次边界误判为终止 |

回合终止时，队列里剩下的较短前缀也要处理。多个并行环境各有自己的队列，不能把环境 A 的动作接上环境 B 的奖励。若外部截断真的定义为任务结束，应按该任务的有限时域语义处理；上表对应本仓库“采集上限”的约定。

## 数据和梯度走哪条路

```text
每个环境的连续经验 → n-step 队列
→ 折扣奖励和、实际步数、末状态、终止标记
→ 回放缓冲区 → 抽样 → 固定目标
旧观察与当时动作 → 在线 Q 预测 → loss → 梯度 → 在线参数更新
```

奖励和、步数、末状态及目标网络估计不通过这次 loss 学习。梯度仍从**最早那次实际动作**的在线预测回到网络参数，不反传穿过环境里的三次运动。

当前 [replay.py](../exercises/chromium_dqn/replay.py) 的 `Transition` 保存单步记录，[train.py](../exercises/chromium_dqn/train.py) 连续收集这些记录。以后实作要在时间关系还明确的采集侧构造多步经验；已经随机打散的一批 `Batch` 无法凭排列恢复轨迹。

## 不要混淆三个“多次”

- **n-step：** 一个训练目标使用几次连续决策的奖励。
- **action repeat：** 一次策略动作在环境内保持多少物理步；它改变决策间隔。
- **多次更新：** 一条经验或一批数据被优化器重复使用多少次。

举一个独立的时间例子：假设每个物理步为 0.01 s，一次动作保持 4 个物理步，三步回报就直接汇总 `0.01 × 4 × 3 = 0.12 s` 内的奖励。目标后面还接着末状态的未来估计，所以不能说策略“只看未来 0.12 s”。动作保持次数与 n 分别设定，n-step 算法并不规定游戏必须使用哪种控制频率。

行为策略中的探索动作也会进入多步奖励序列；普通未修正 n-step 与目标贪心策略存在差别，长 n 会增加这种影响。PPO 的 [[PPO及感知四足课程路线|101 课 GAE]] 也利用时间上的反馈，但它构造优势，不能与这里的 Q 目标直接互换。

以后实作先检查终止、截断、多环境隔离和队尾处理，再比较 n=1 与一个候选 n；不同时更换奖励或动作保持。
