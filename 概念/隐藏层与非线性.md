# 隐藏层与非线性

隐藏层位于网络输入和最终输出之间，用中间特征重新表示输入。若多个线性层之间没有非线性函数，它们可以合并成一个线性层，整体表达能力没有获得本质变化。

```text
Linear → Linear
仍等价于一个 Linear

Linear → ReLU → Linear
可以根据输入区域启用不同隐藏路径
```

## ReLU 的职责

$$
ReLU(z)=\max(0,z)
$$

- 正值原样通过；
- 零和负值变成 0；
- 自身没有可学习参数；
- 通过不同隐藏单元的开关组合形成分段关系。

两个隐藏单元就能表示一条直线不能全局表示的绝对值：

$$
|x|=ReLU(x)+ReLU(-x)
$$

## 把公式变成三行数字

两层纯乘加可以写成 `3 × (2x + 1) + 4 = 6x + 7`；层数增加了，整体仍是一条直线。加入 ReLU 后，绝对值例子使用两条不同的通路：

| x | ReLU(x) | ReLU(-x) | 两项相加 |
| --- | --- | --- | --- |
| -2 | 0 | 2 | 2 |
| 0 | 0 | 0 | 0 |
| 3 | 3 | 0 | 3 |

同一组规则随输入区域启用不同路径，能形成折线。它提供表达这种关系的能力，但不保证训练一定学到合适关系；若输入根本缺少速度等关键信息，单纯增加宽度也不能恢复它。

## 隐藏宽度的边界

输入宽度由观察特征数量决定，输出宽度由动作数量决定；隐藏宽度是表达容量选择。第 061 课使用 3 只是为了手算，不代表 CartPole 的最佳宽度。常见的 64 也不是公式推导出的唯一答案，需要结合任务与受控实验选择。

最终 Q 值允许为负，因此通常只在隐藏层后使用 ReLU，不在最后的 Q 值输出后强制 ReLU。
