# 回报分布与 C51

这是进阶选读。前面已经知道 Q 估计一个动作的平均长期回报；本篇再增加“同一个平均数背后可能有不同结果分布”的视角。

## 为什么一个平均数不够描述结果

一种动作总得到 0，另一种动作一半得到 -2、一半得到 2，平均都是 0，但结果的波动不同。

Distributional RL 学习回报分布；这里的 distributional 指回报如何分布，不是多台机器分布式训练。C51 用固定的 51 个回报位置，学习每个位置的概率。动作仍通常按期望 Q 选择，学到分布不会自动变成避险策略。[C51 原论文](https://arxiv.org/html/1707.06887v1)

这些概率不是选择动作的概率，也不能直接解释为模型对自己是否正确的置信度。

## 先用三个位置看懂

为方便手算，暂用三个固定位置 `z = [-2, 0, 2]`，不声称这个三点例子就是 C51。某个动作的预测概率为 `[0.2, 0.5, 0.3]`。

| 回报位置 | 概率 | 对平均回报的贡献 |
| --- | --- | --- |
| -2 | 0.2 | -0.4 |
| 0 | 0.5 | 0 |
| 2 | 0.3 | 0.6 |

所以该动作的 Q 为 `-0.4 + 0 + 0.6 = 0.2`。计算规则是“每个可能回报乘其概率，再相加”：

$$Q(s,a)=\sum_j z_j p_j(s,a)$$

固定的是回报位置 `z_j`；网络学习的是概率 `p_j`。对每个动作分别在回报位置这一维归一化概率，不能在动作维归一化后误当作策略概率。

## 奖励怎样改变整个目标分布

考虑一条未终止经验，即时奖励为 1，折扣为 0.5。目标网络在选定下一动作处的分布也取 `[0.2, 0.5, 0.3]`，位置仍为 `[-2, 0, 2]`。

将未来回报位置逐个换成“本次奖励加折扣后的未来”：

```text
1 + 0.5 × (-2) = 0，携带概率 0.2
1 + 0.5 × 0    = 1，携带概率 0.5
1 + 0.5 × 2    = 2，携带概率 0.3
```

新位置 `[0, 1, 2]` 不都在原来的固定网格上，因此要把概率投回固定位置：

1. 位置 0 的概率 0.2 全部留在 0。
2. 位置 1 在 0 和 2 的正中间，概率 0.5 各分 0.25。
3. 位置 2 的概率 0.3 全部留在 2。
4. 目标概率按 `[-2, 0, 2]` 排列为 `[0, 0.45, 0.55]`。

目标平均数是 `0×(-2) + 0.45×0 + 0.55×2 = 1.1`，也等于 `1 + 0.5 × 0.2`。平均值的对应关系仍保留，训练信号却包含整份分布。

## 损失与梯度怎样连接

假设旧观察实际动作的在线预测也是 `[0.2, 0.5, 0.3]`。目标是刚算出的 `[0, 0.45, 0.55]`，希望在线预测把更多概率放到位置 2。

交叉熵比较预测与目标概率：

$$L=-\sum_j m_j\log p_j$$

`m` 是投影后的固定目标，`p` 是在线网络由 logits 归一化得到的概率；logits 是转成概率之前的实数输出。使用自然对数，本例为：

```text
L = -0.45 × ln(0.5) - 0.55 × ln(0.3)
  ≈ 0.974101
```

对在线 logits 的梯度是 `p - m = [0.2, 0.05, -0.25]`。梯度下降会降低前两个位置的相对倾向，提高第三个。loss 经概率归一化与 logits 连接到在线网络，反传写梯度后由优化器更新；目标概率、固定位置和投影计算不接收这一轮梯度。

## 终止、范围和动作选择

- 若自然终止且奖励为 1，所有未来位置都收缩到 1，再投影成 `[0, 0.5, 0.5]`；不能保留未来的分散程度。
- 超出固定支持范围的回报会被截到边界，范围选错会丢信息。51 是论文中的位置数量，不是 51 个动作，也不是通用最优常数。
- 投影恰好落在网格点时，质量必须完整留在该点，不能因为上下索引相等而丢掉概率。
- 选下一动作通常先比较各动作的期望 Q，再取被选动作的整份分布。是否使用 Double 的选择/估价分工，要看具体组合；C51 本身不自动等于 Double DQN。
