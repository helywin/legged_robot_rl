# NoisyNet 与参数噪声探索

这是可选自学内容，解释网络参数中的噪声怎样带来探索，也是理解原版 Rainbow 组合的一部分。

## 换一种产生探索的地方

ε-greedy 是先算确定的 Q，再用一定概率改选随机动作。NoisyNet 在网络参数中引入可学习幅度的噪声，使 Q 本身随噪声变化，然后根据变化后的 Q 选择动作。[Noisy Networks 原论文](https://arxiv.org/html/1706.10295v3)

例如原来两个动作的 Q 为 `[1.0, 0.9]`，加入一次参数噪声后的输出变成 `[0.8, 1.1]`，即使取最大 Q 也会改选动作 1。这里探索来自估值网络的变化，不是环境奖励被随机改掉。

## 一个参数的数字

最小示意把有效权重写成：

$$w=\mu+\sigma\varepsilon$$

μ 是学习到的中心值，σ 是学习到的噪声幅度参数，ε 是这次抽到的随机数。μ、σ 都属于模型；ε 是本次随机样本，不是优化器要训练的参数，也不是 ε-greedy 的概率。

设输入 x=2，μ=1，σ=0.1，本次 ε=-1：

```text
有效权重 w = 1 + 0.1 × (-1) = 0.9
当前预测 q = w × 2 = 1.8
固定学习目标 y = 2
平方损失 L = (1.8 - 2)² = 0.04
```

loss 对 q 的梯度为 -0.4；q 对 μ 的导数为 x=2，对 σ 的导数为 `ε×x=-2`。因此 μ 的梯度为 -0.8，σ 的梯度为 0.8。

以学习率 0.05 更新这两个独立参数：

```text
μ：1 - 0.05 × (-0.8) = 1.04
σ：0.1 - 0.05 × 0.8  = 0.06
若保持同一次 ε，新的 q = (1.04 - 0.06) × 2 = 1.96
```

噪声幅度在本例中减小，因为这一方向能减小损失；换一条数据也可能增大。不能概括为“训练越久噪声必然一直减小”。

## 一次更新中什么保持固定

本轮先抽噪声，使用它完成前向和目标构造，再反传。求导把 ε 当已知常量，梯度通过 μ、σ 的计算路径回到参数。optimizer 管理 μ、σ 的引用，读取对应 `.grad` 修改它们；随机数本身不会因 `backward()` 被训练。

噪声何时重采样、在线网络与目标网络如何分别采样、同一批次是否共享噪声，都属于实现契约，不能在一次 loss 的中途任意重抽。原论文给出了具体的抽样与更新安排，组合算法应明确采用哪种。

## 和其他“噪声”分开

| 名称 | 噪声在哪里 | 学习或验证重点 |
| --- | --- | --- |
| ε-greedy | 最终动作选择 | 随机动作机会随什么计数衰减 |
| NoisyNet | 价值网络参数 | 噪声参数、抽样时刻、Q 的变化 |
| 观察噪声 | 传感器输入 | 感知误差下策略是否稳健 |
| PPO 高斯策略 | 连续动作分布 | 动作密度、探索幅度及概率比 |

NoisyNet 的 σ 不是 PPO 输出动作分布的标准差，两者所在位置与训练目标不同。使用 NoisyNet 的实现常替代 ε-greedy，但具体组合和评测时是否关噪声必须记录；不能只设置 `epsilon=0` 就断言推理已经确定。

当前游戏网络是普通线性层。以后实作时需把探索设置、噪声状态、保存加载与评测规约一起核对；本次没有替换网络或启动训练。
