# 优先经验回放 PER

这是可选自学资料。先理解均匀回放：经验保存在池里，抽样后不会被删掉。

## 什么经验值得多学

PER 想把更多更新机会给当前预测与目标差得较大的经验。常见信号是 TD 误差 `δ = target - Q预测` 的绝对值。它是“还有多少没预测对”的代理量，不是对事件重要性的完美识别。[PER 原论文](https://arxiv.org/html/1511.05952v4)

算法不会天然识别“成功躲避”或“差点中弹”。大误差可能来自有价值的事件，也可能来自噪声、错误奖励或异常观察。失败经验和成功经验都可能被多抽。

## 三条经验怎样分配概率

假设三条经验最近计算出的绝对 TD 误差是 `[0.9, 1.9, 6.9]`。先加一个小正数，避免误差为零时完全抽不到；为方便手算取 ε=0.1，优先级就是 `[1, 2, 7]`。

先看希望解决的计算：将优先级变成总和为 1 的抽样概率，并用 α 调节偏向程度。

$$
p_i=|\delta_i|+\varepsilon,\qquad
P(i)=\frac{p_i^{\alpha}}{\sum_j p_j^{\alpha}}
$$

α=1 时，优先级之和为 10，三条经验的概率是 `[0.1, 0.2, 0.7]`。α=0 时三者都是 1/3，回到均匀抽样。ε 是优先级的正数下限，不是动作探索的 epsilon。

## 多抽以后，为什么还要给 loss 加权

第三条从 1/3 的机会变成 0.7；直接对新批次平均 loss，会更加偏向它。因此 PER 使用重要性采样权重，对这种抽样偏差作补偿。

令 N=3 是当前池中经验数，β 控制补偿程度：

$$
w_i=(N P(i))^{-\beta}
$$

β=1 时，本例未归一化权重为 `[10/3, 5/3, 10/21]`。各自乘抽样概率，都会得到 1/3。因此，在固定池、固定概率与固定单条梯度的条件下，期望贡献恢复为均匀抽样的贡献。

为控制步长尺度，常把权重除以池内最大权重；本例变成 `[1, 1/2, 1/7]`。这保留相对补偿，但整体梯度会缩放。用批内最大值归一化是另一种实现约定，不能与池内最大值的推导混称完全相同。

β=0 不补偿；中间值只部分补偿。它不保证每个有限批次恰好无偏，也不是纠正 n-step 行为策略差别的万能权重。

## 一次具体更新怎样连接

假设本批抽到第 0、2 条，平方损失分别为 `0.9²=0.81` 与 `6.9²=47.61`。采用上面的归一化权重：

```text
逐条加权：0.81 × 1，47.61 × (1/7)
再求批次平均：(0.81 + 6.8014286) / 2 = 3.8057143
```

必须保留每条经验的 loss，先乘自己的权重再平均。若先把 loss 平均成一个数，再乘一个平均权重，就丢失了“哪条经验对应哪个权重”。

```text
池中优先级 → 抽样概率 → 样本、索引、权重
样本 → 固定目标与在线预测 → 每条 TD 误差与 loss
权重 × 每条 loss → 平均 loss → 反传 → 在线参数更新
脱离计算图的误差数值 → 写回对应索引的优先级
```

权重和优先级作为本轮固定数据，不让梯度沿它们回到网络。网络梯度来自加权后的在线预测误差。优先级可以记录本轮更新前计算的误差，也可额外重算更新后的误差；实现需写明时刻，不能把旧缓存叫作实时精确误差。

新经验还没有误差时，常先给当前最大优先级，让它有较高机会被学习。随机抽样下，“较高机会”不等于有限预算内绝对保证抽到。

## 对应代码与以后实作的边界

[tensor_replay.py](../exercises/chromium_dqn/tensor_replay.py) 和教学版 [replay.py](../exercises/chromium_dqn/replay.py) 当前采用均匀无放回抽样。[agent.py](../exercises/chromium_dqn/agent.py) 当前先得到已归约的 MSE/Huber loss；PER 还需要索引、抽样概率、逐样本 loss 和优先级写回。

上面的概率公式按单次分类抽样或有放回抽样理解。不能把当前无放回抽样简单换成加权选择，再不检查概率定义就套用同一重要性权重。以后先用小池验证频率与权重，再按需要使用树结构加速。

池槽被新经验覆盖时，优先级也要一起更新；重复抽到同一索引时写回规则要明确。PER 会改变数据分布，可能放大异常样本，所以需要同时观察优先级集中程度和独立评测效果。
