# 自动求导与梯度

损失用一个数字表示预测与目标之间的差距。自动求导根据产生损失的计算路径，计算损失对每个模型参数的梯度，并把结果写入参数的 `.grad`。

```text
参数 → 预测 → 损失
              ↓ backward
参数.grad ← 梯度
```

梯度的符号表示增大参数时损失变化的方向，绝对值表示当前局部的敏感程度。

## 职责边界

- `backward()` 计算梯度，不直接修改参数；
- 梯度不是奖励，也不是新的参数值；
- 参数更新还需要学习率和明确的更新步骤或优化器；
- 多次反向计算前怎样清空旧梯度属于后续概念。
