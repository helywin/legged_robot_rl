# PyTorch 张量

张量是 PyTorch 用来保存和计算数字的容器。它除了数值，还记录数据类型和维度。标量张量只保存一个数，长度为 2 的一维张量可以保存两项观察。

张量逐项乘法会让相同位置的数字分别相乘；`.sum()` 再把多项结果相加：

```text
[观察1, 观察2] × [权重1, 权重2]
→ [贡献1, 贡献2]
→ sum
→ 一个标量预测张量
```

## 数量相同，形状不一定相同

| 形状 | 例子 | 应怎样读 |
| --- | --- | --- |
| `()` | `2.0` | 一个标量，没有轴 |
| `(1,)` | `[2.0]` | 一维向量，里面一个元素 |
| `(2, 3)` | 两行、每行三项 | 若约定按行放样本，就是两条观察、每条三个特征 |

轴的业务含义不是张量自动知道的，必须由接口约定。浮点数适合观察和 Q 值；动作索引通常用整数；真假标记可用布尔值。数据还要放在兼容的设备上，不能只检查数字看起来正确。

## 一个不会自动报错的形状陷阱

假设两条样本的预测分别为 1、2，目标也为 1、2。本应逐条比较，损失为 0。

但预测保存成列 `[[1], [2]]`，形状 `(2, 1)`；目标保存成 `[1, 2]`，形状 `(2,)`。二者相减时，广播会把它们扩展为二维比较：

```text
[[1],       [1, 2]       [[1-1, 1-2],       [[ 0, -1],
 [2]]   -            →    [2-1, 2-2]]   =    [ 1,  0]]

平方后求平均 = (0 + 1 + 1 + 0) / 4 = 0.5
```

程序比较了“每个预测与每个目标”，已经不是原来的两条经验了。计算逐样本损失前，应保证预测和目标都为 `(B,)`，或都为 `(B, 1)`，并确认行对应关系。只核对元素总数不够。

这里的广播规则据 [PyTorch 官方说明](https://docs.pytorch.org/docs/stable/notes/broadcasting.html)；上表数字是手算示例。进一步连接 [[概念/批量张量与逐行动作索引]]、[[概念/回放样本的字段批量化]]。

逐元素乘法 `*` 和矩阵乘法 `@` 也不同：前者逐项相乘，后者按行列配对后求和；不能看到形状能运行就互相替换。

## 职责边界

- 张量是数据容器，不等于神经网络；
- 创建张量不等于训练；
- `.item()` 可以读取单元素张量中的 Python 数值，但网络计算通常应继续保留张量；
- 批次如何对应经验见上述链接；张量参与计算是否记录梯度，要另看 [[概念/自动求导与梯度]]。
