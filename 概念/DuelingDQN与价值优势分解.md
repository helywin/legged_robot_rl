# Dueling DQN 与价值优势分解

这是可选自学资料。它调整 Q 网络怎样组织输出，可以与普通 DQN 或 Double DQN 的目标规则配合。

## 从局面与动作差别分开想

如果飞机处于宽阔安全的位置，很多移动动作短时间内都差不多。可以让网络共享一部分“这个局面整体怎样”的信息，再学习不同动作之间的差别。

Dueling 将共享特征分成一个标量分支 V 和一个每动作都有输出的分支 A，再合成 Q 值。这仍是动作价值网络，最终按 Q 选择动作。[Dueling 原论文](https://arxiv.org/html/1511.06581v3)

```text
观察 → 共享特征 → V：一个数 ───────────┐
               → A：每个动作一个数 → 合成每个动作的 Q
```

## 为什么不直接相加

直接写 `Q = V + A` 可以表达“整体水平加动作差别”的直觉，却没有固定两个分支的分工。如果把 V 加 10、所有 A 都减 10，Q 完全不变，两个分支的职责便不唯一。

常见实现先减掉 A 在动作维上的平均值，再相加。令 K 是动作数：

$$
Q(s,a)=V(s)+A(s,a)-\frac{1}{K}\sum_{b=1}^{K}A(s,b)
$$

V 和 A 都来自同一观察的网络输出。这里的减平均不是在时间维或 batch 维做，也不是对奖励减平均。

## 三个动作算一遍

假设 V 分支输出 2，A 分支输出 `[1, -1, 3]`。

1. A 的平均是 `(1 - 1 + 3) / 3 = 1`。
2. 减平均后为 `[0, -2, 2]`。
3. 加上 V 得到 Q：`[2, 0, 4]`。
4. 按最大 Q 选择动作 2。

若只把 V 从 2 改为 3，Q 变成 `[3, 1, 5]`，整体估值上升，动作排序不变。若改变 A 的相对差别，动作排序才可能改变。

采用减平均聚合时，V 等于各动作 Q 的算术平均，不自动等于贪心策略的理论状态价值。本例平均 Q 是 2，最大 Q 是 4。网络分支叫 V，并不表示它拥有独立的真实价值标签。

## 只训练一个动作，两个分支都能收到梯度

继续用上面的输出。经验中实际做了动作 2，固定目标为 5，因此 Q 预测为 4，平方损失 `(4 - 5)² = 1`。

先把 V 和三个 A 当作独立可调数字，观察梯度：

- loss 对 Q2 的梯度是 `2 × (4 - 5) = -2`。
- Q2 对 V 的导数是 1，所以 V 的梯度是 `-2`。
- Q2 对 A2 的导数是 `1 - 1/3 = 2/3`，所以 A2 梯度是 `-4/3`。
- Q2 也包含 A0、A1 的平均项；对每个的导数是 `-1/3`，对应梯度各为 `2/3`。

学习率取 0.1，更新后 V=2.2，A 约为 `[0.9333, -1.0667, 3.1333]`；重新合成的 Q 约为 `[2.1333, 0.1333, 4.3333]`。实际动作的预测朝 5 移动，其他输出也发生联动。

真实网络中，梯度继续通过两个分支回到共享特征层。loss 保留本轮合成和前向的计算图，`backward()` 写入对应参数的 `.grad`，优化器更新其管理的参数；目标支路保持固定。并没有为 V、A 分别发放环境奖励。

## 对应现有代码与常见误解

[network.py](../exercises/chromium_dqn/network.py) 当前用一个普通输出层直接给出所有动作 Q。Dueling 会改变网络的输出结构与合成方式；在线和目标网络必须采用相同结构，旧结构检查点不能假装直接兼容。

| 容易混淆的名字 | 实际职责 |
| --- | --- |
| Double DQN | 下一动作由谁选、由谁估值 |
| Dueling DQN | 一个 Q 网络怎样分解并合成输出 |
| PPO 的 Actor-Critic | 一个网络负责动作分布，价值估计帮助构造策略学习信号 |

Dueling 的 A 是网络内部的相对输出，不是 PPO 根据轨迹计算出的优势标签。两个分支也不是两个互相对抗的智能体。

以后实作先验证减平均的维度、输出形状与梯度，再保持任务和预算不变做对照。多加分支可能有用，但不能补回观察里缺少的速度或修复错误奖励。
