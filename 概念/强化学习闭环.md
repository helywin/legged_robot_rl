# 强化学习闭环

先看策略如何使用已有本领与环境交互：

```text
环境给出观察 → 策略选择动作 → 环境执行动作
→ 返回新观察和奖励 → 策略继续决策
```

这个闭环只描述各部分怎样协作，不规定必须使用 Q-learning、DQN 或 PPO。**仅仅反复交互，还不能证明发生了学习。** 训练时还需要另一条连接：

```text
收集交互经历 → 算出需要改进的量 → 更新 Q 表或网络参数
                                         ↓
                              之后的决策使用更新后的本领
```

## 用走格子区分“走了一步”和“学了一次”

假设位置为 2，动作只有左、右，位置 3 是终点：

| 环节 | 本次具体发生什么 | 什么会改变 |
| --- | --- | --- |
| 读取观察 | 得到位置 2 | 尚未移动 |
| 选择动作 | 根据当前规则选择右 | 只得到决定，Q 表尚未更新 |
| 环境执行 | 从位置 2 移到位置 3 | 环境位置改变 |
| 环境反馈 | 奖励 1，任务结束 | 得到一条可供学习的经历 |
| 算法更新 | 用这条经历调整位置 2 向右的估计 | Q 表或网络参数改变 |

前四行可以在随机策略或冻结策略下发生；第五行才涉及学习。也可以先收集多步，再集中更新，不要求环境每走一步就更新一次。

一局结束后，环境可以重置到起点，已学到的参数通常继续保留。像重新摆好棋盘：棋子回到原位，不代表棋手忘记前一局。

这只是机制示例，不是新增训练结果。更新公式见 [[概念/Q-learning更新]]，三个数量的区别见 [[概念/DQN训练的三种计数]]。
