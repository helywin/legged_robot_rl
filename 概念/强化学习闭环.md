# 强化学习闭环

强化学习不是一次预测，而是反复进行的交互循环：

```text
环境给出观察 → 策略选择动作 → 环境执行动作
→ 返回新观察和奖励 → 策略继续决策
```

这个闭环只描述各部分怎样协作，不规定必须使用 Q-learning、DQN 或 PPO。
