# 神经网络参数与预测

参数是模型内部可学习、也可以冻结的数字，多个观察会共同使用它们。它们不是观察、动作、奖励或某一个观察专属的 Q 值。

在本页的离散动作 Q 网络中，预测是使用当前参数，根据一个观察计算每个动作各自的 Q 值；其他网络也可以预测概率、状态价值等，输出含义取决于任务：

```text
观察 → 共享参数计算 → 每个动作的 Q 值
```

Q 表通过观察编号读取一行；参数估计器根据观察现场计算一组数。两者都要给动作选择提供“每个动作一个 Q 值”，但参数共享使一个更新可能影响多个观察。

## 职责边界

- 预测只读取参数，不修改参数；
- 最大 Q 值动作属于利用，训练时仍可探索；
- 预测是当前估计，不保证正确；
- 与经验构造的目标 Q 值比较可以定义训练损失，但目标本身也有估计误差；策略效果还需独立评估。
