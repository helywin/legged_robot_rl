# 批量张量与逐行动作索引

批量张量把多条结构相同的经验沿第 0 维堆在一起。对于离散动作 Q 网络：

```text
observations.shape = (经验数量, 观察数量)
q_values.shape     = (经验数量, 动作数量)
```

每条经验记录的实际动作可能不同，因此必须在每一行使用自己的动作列号，得到形状为 `(经验数量,)` 的 `selected_q_values`。

## 为什么普通索引不够

对二维 Q 值张量使用 `q_values[executed_actions]` 会索引第 0 维，也就是选择经验行；它不会自动理解为“每一行分别选择一个动作列”。逐行选列需要同时保留行与列的对应关系，可使用沿动作维的 `gather`。

## 计算图边界

- 动作编号是整数索引，不需要梯度；
- 选出的 Q 值仍连接到在线网络参数；
- 只完成前向和索引不会修改网络参数；
- 后续 loss 可以同时使用这一批 selected Q 值完成一次批量反向更新。
