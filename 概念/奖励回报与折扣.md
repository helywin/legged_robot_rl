# 奖励、回报与折扣

奖励是环境在一步交互后给出的反馈；回报是从某个时刻开始，把后续奖励累计起来；折扣规定较晚的奖励在这个累计中占多少分量。Critic 预测的是回报，不只是下一步奖励。

## 奖励由哪里来

任务的奖励规则规定哪些结果得分或扣分，环境在动作执行后根据实际转移计算奖励。比如到达目标获得奖励、碰撞受到惩罚。Actor 选择动作，Critic 估计收益，两者都不负责制定这条规则。

奖励可以经常出现，称为稠密奖励；也可以只在少数事件出现，称为稀疏奖励。稀疏不等于只能在回合结束发奖，中途达成事件也可以发奖。PPO 和 DQN 都可以使用这两类任务。

阶段性奖励可以作为任务设计的一部分，但添加它会改变或塑造学习目标；把已有奖励按阶段统计则只是数据整理。这两件事不能混为一谈。

## 回报从当前时刻向后看

“本局到现在拿了多少分”是历史累计；“从当前时刻往后能拿多少分”才是当前价值要预测的对象。过去奖励不应算成当前动作之后的结果，本次动作执行后立刻收到的奖励则要包含。

这里统一记号：观察为 $s_t$，执行动作为 $a_t$，执行后收到奖励 $r_t$ 和下一观察 $s_{t+1}$。$G_t$ 是从这次动作开始的回报，$\gamma$ 是每个决策步的折扣系数。

$$
G_t=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots
$$

不同起点对应不同回报。最后的成功奖励可以进入多个较早时刻的回报，这是分别评价“从这里往后”的结果，没有让环境重复发奖，也不是把奖励平均分给动作。

## 折扣表达怎样重视较远的奖励

$\gamma$ 通常在 0 到 1 之间。为 0 时只考虑本步奖励；越接近 1，较远奖励保留的分量越多。有限回合中为 1 表示不打折；无限持续任务还需检查累计是否有限。

折扣不会修改环境已发出的奖励。它也不是学习率：折扣影响所追求的回报，学习率影响参数怎样更新。较大折扣不保证训练更好。

例如假设三步奖励为 `[1, 0, 2]`，之后真正终止，取 $\gamma=0.9$：从第一步起的回报为 $1+0.9\times0+0.9^2\times2$，从第二步起则是 $0+0.9\times2$。这个例子只说明时间归属，不要求做手算。

通常每个决策步打一次折，不是每秒一次。修改动作保持时间，也会改变同一折扣对应的实际时间跨度，见 [[概念/动作保持与观察时间对齐]]。

## 没结束也能使用已有反馈

已经记录的奖励马上可用，不必等整局结束才能训练。未知的是采样窗口之后的结果。用 Critic 对接续观察的价值预测补这部分，称为自举：

```text
片段收益估计 = 片段内实际奖励的折扣累计 + 折扣后的末状态价值预测
```

用的是最后一个动作执行后的观察，不是动作前观察，也不是重置后新一局的观察。接了预测的结果是回报估计或训练目标，不能声称全由真实奖励组成。

| 边界 | 未来怎样处理 |
| --- | --- |
| 任务真正终止 | 后续价值为零，但最后一步奖励仍保留 |
| 本批采样够了，任务可继续 | 用末状态价值补尚未观察的未来 |
| 时间上限导致停止 | 按任务定义判断；若只是外部截断，通常保留最终观察的价值，不接新回合数据 |

真实奖励让估计有纠正依据；如果策略从未探索到有信息的奖励，Critic 不能凭空推断成功在哪里。

## 为什么能倒着整理

当前回报可以复用下一时刻的回报：$G_t=r_t+\gamma G_{t+1}$。完整回合从终止后的零开始往前算；未结束片段从末状态价值开始往前算。环境仍向前运行，倒序只是数据整理，不是神经网络反向传播。
