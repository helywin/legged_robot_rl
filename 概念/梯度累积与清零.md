# 梯度累积与清零

PyTorch 的 `backward()` 默认把本次梯度加到参数已有的 `.grad` 上。这叫梯度累积：

```text
第二次 backward 后的 grad = 第一次留下的 grad + 第二次新算的 grad
```

如果希望本次更新只使用本批数据的梯度，就要在本次反向累积开始前清空旧梯度。习惯上放在前向之前，也可以放在前向之后、`backward()` 之前：

```python
optimizer.zero_grad()
```

“清空”可以是把 `.grad` 设为 `None`，不保证打印时看到一个全零张量。它没有重置参数、训练进度或优化器的动量历史。

## 用同一组数字看“忘记清空”

沿用 [[概念/自动求导与梯度]] 的 x = 2、w = 0.5、b = 0.1、目标 1.5。如果两次都重新前向，中间既不更新参数，也不清梯度：

| 时刻 | w.grad | b.grad | 参数是否更新 |
| --- | --- | --- | --- |
| 清空后 | None 或 0 | None 或 0 | 否 |
| 第一次反向后 | -1.6 | -0.8 | 否 |
| 第二次反向后 | -3.2 | -1.6 | 否 |

此时用学习率 0.1 的普通 SGD 更新，得到 w = 0.82、b = 0.26，新预测为 1.9；正确使用一份梯度时，预测应为 1.5。重复累积把本次步幅扩大了。

这里强调“重新前向”，因为普通反向完成后会释放求导所需的中间保存数据，不能把重复对同一个旧图 `backward()` 当成默认训练写法。

## 有意累积怎样保持平均的含义

若想把两个小批次合成一次更新，就先清空，再各自反向，最后只 `step()` 一次。两个小批次样本数相等、损失都是各自的均值时，各自损失除以 2 后再反向，才对应合并批次的平均梯度；大小不等应按样本数加权。

这个等价关系针对同一组参数上、可按样本分解的损失。包含依赖批次统计的层时，拆批前向本身也可能不同。详见 [[概念/批量损失与梯度平均]]。

## 职责边界

- `zero_grad()` 清空梯度，不恢复或清空模型参数；
- 它通常放在本轮预测和 `backward()` 之前；
- 有意累积多个样本的梯度也是一种训练方法，但必须明确设计，不能把忘记清空当作这种方法；
- 清空梯度只是训练循环的一个环节，不代表模型已经完成训练。
