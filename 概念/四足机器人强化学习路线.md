# 四足机器人强化学习路线

四足分支与游戏共享观察、动作、奖励、策略和评估基础。PPO 先在少量离散动作的小环境中学习，再扩展到连续关节动作和 Isaac Lab。2026-09-12 起 DQN 暂停，下一课从 200 开始。

```text
已有基础 → 自写小型 PPO → 连续控制与并行采样
→ Go2 平地、控制与地形实验 → learn 的高程图与历史
→ 状态估计与辅助训练 → 激光点云编码与运动补偿
→ 感知和本体融合 → 独立评测 → Gazebo 跨仿真
→ 条件具备后的真机验证与自己的报告
```
