# 经验回放

经验回放先保存环境交互产生的旧经验，再随机抽取其中一部分用于参数更新。

一条经验通常包含：

```text
旧观察、动作、奖励、新观察、terminated、truncated
```

## 职责

- 保留旧经验，使同一条经验能够重复用于训练；
- 混合不同时间和位置的经验，避免更新只追随最近的一小段连续数据；
- 容量满时淘汰最旧经验，限制内存占用。

## 随机不等于永不重复

本仓库早期的 `random.sample(...)` 写法在同一批内不重复选同一条，但不同更新之间允许再次抽到以前的经验。这是具体抽样方法的约定，不是所有 replay 的通用限制；有放回抽样允许批内重复。回放的目的之一就是重用获取成本较高的环境经验。

若这段统计期间缓冲区固定为 $N$ 条、没有新增或淘汰、每次均匀抽 $B$ 条、共更新 $U$ 次，则每条经验被抽中的期望次数为：

$$
\frac{U \times B}{N}
$$

例如 N = 100、B = 10、U = 20，期望为 2 次，不保证每条都恰好用两次。缓冲区持续增长、覆盖旧经验或使用优先抽样时，不能直接拿最终 N 套用此式。

随机抽样不会从少量固定经验中创造新信息；持续大量更新同一批旧经验会增加过度拟合的风险，也不能保证没见过的情形学得好。

## 三种“保存过去”分别做什么

| 保存内容 | 主要用途 | 能否随便打乱 |
| --- | --- | --- |
| 当前观察中的最近几帧 | 让策略推断运动 | 不能打乱帧顺序 |
| 同一段轨迹 | 计算连续多步奖励等 | 涉及时序计算时不能打乱 |
| 一步 DQN 回放中的完整经验 | 重用不同时间发生的转移 | 可抽取完整条目，但条目内部字段必须对齐 |

通常保存经历本身，训练时重新计算当前预测和 target；并非把采集时的旧目标永远当成正确答案。序列模型、n-step 和 PER 的回放结构还会增加对应要求，见 [[图谱/DQN改进方法自学路线]]。

## 不负责什么

- 不替环境产生奖励；
- 不替策略选择动作；
- 不改变 Q-learning 目标或误差公式；
- 不在冻结评估阶段继续训练参数。
