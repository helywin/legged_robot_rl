# 回放样本的字段批量化

经验回放随机抽出的是若干条完整经验对象。进入 PyTorch 网络前，需要保持抽样顺序，把所有旧观察、动作、奖励、下一观察和真正终止标记分别收集成张量。

```text
Transition 对象列表
→ 同名字段分别纵向收集
→ observations float32
→ actions long
→ rewards float32
→ next_observations float32
→ terminated bool
```

## 抽样可以换顺序，字段不能各换各的

假设抽到两条经验：A 执行动作 1、奖励 -0.5；B 执行动作 0、奖励 2。

| 抽样顺序 | observations | actions | rewards |
| --- | --- | --- | --- |
| A、B | A 的旧观察、B 的旧观察 | 1、0 | -0.5、2 |
| B、A | B 的旧观察、A 的旧观察 | 0、1 | 2、-0.5 |

两种都可以。但若保持观察为 A、B，却单独把动作排序成 0、1，就把 B 的动作嫁接给 A；形状和类型可能全对，经历已经被改错了。`next_observations` 和结束标记也要跟随整条记录移动。

动作编号是“取哪一列”的地址，不是连续测量值，因此这里使用整数类型；奖励和观察用于数值计算，使用浮点类型。整理数据既不创造新经历，也不自动训练模型。

## 关键边界

- 所有字段的第 $i$ 行必须仍属于同一条经验；
- dtype 由字段在计算中的职责决定；
- `truncated` 应继续保存在经验中，但不能与 `terminated` 混成 target 的未来开关；
- 字段批量化只整理数据，不执行网络预测或参数更新。
