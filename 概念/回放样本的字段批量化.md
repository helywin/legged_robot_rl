# 回放样本的字段批量化

经验回放随机抽出的是若干条完整经验对象。进入 PyTorch 网络前，需要保持抽样顺序，把所有旧观察、动作、奖励、下一观察和真正终止标记分别收集成张量。

```text
Transition 对象列表
→ 同名字段分别纵向收集
→ observations float32
→ actions long
→ rewards float32
→ next_observations float32
→ terminated bool
```

## 关键边界

- 所有字段的第 $i$ 行必须仍属于同一条经验；
- dtype 由字段在计算中的职责决定；
- `truncated` 应继续保存在经验中，但不能与 `terminated` 混成 target 的未来开关；
- 字段批量化只整理数据，不执行网络预测或参数更新。
