# 共享参数与预测联动

神经网络不是为每条观察保存一套独立参数。不同观察调用同一个模型时，都会使用同一组权重和偏置。

```text
观察 A ─┐
观察 B ─┼→ 同一组网络参数 → 各自的 Q 值
观察 C ─┘
```

一条训练经验只负责产生本轮 loss 和梯度，但 optimizer 修改的是共享参数。修改完成后，其他没有进入本轮 loss 的观察再次前向时也会读取新参数，因此预测可能变化。

## 直接变化与间接变化

- 实际动作的输出层行直接连接 loss，因此本轮可以收到梯度并更新；
- 未选动作的输出层行可能保持不变；
- 但所有动作输出都读取共享隐藏表示，所以隐藏层改变后，未选动作 Q 值仍可能间接变化；
- 没参加训练的观察不在本轮计算图里，但下一次前向会使用更新后的共享参数。

## 与 Q 表的区别

Q 表可以只改一个明确格子 `Q(s,a)`，其他格子保持不变。神经网络修改的是一个共享函数的参数，一处训练通常会影响一片输入区域。

这种联动让网络可能把经验推广到相似观察，也带来干扰其他预测的风险。不能因为当前样本 loss 下降，就推断所有观察都变得更准确。
