# 回放预填充与训练起点

回放预填充是指：训练开始时先让环境交互并收集经验，缓冲区达到设定数量后，才允许第一次参数更新。

```text
环境交互与存经验
→ 数量未达 warmup_size：不训练
→ 数量达到 warmup_size：允许回放抽样和参数更新
```

## 为什么需要

- 缓冲区少于 batch size 时，根本无法抽出完整一批；
- 刚好只有 batch size 条时，每批只能包含全部最早经验，还没有抽样成员的多样性；
- 先积累更多状态、动作和反馈，可以避免网络一开始就过度追随极少数早期经验。

`warmup_size` 至少不能小于 batch size，但真实设置往往还会更大。没有一个对所有任务通用的固定数字；它要与缓冲区容量、batch size、交互速度和更新频率一起解释。

## 关键边界

- 预填充期间环境仍在交互，不是整个程序暂停；
- 没有 optimizer 更新时，在线更新计数保持 0；
- 预填充只提供起始数据，训练开始后环境仍应继续增加新经验；
- 预填充不保证经验足够优质，行为多样性还与探索策略有关；
- 预填充不是神经网预训练，期间参数没有通过 loss 学习。
