# DQN 目标 Q 值

DQN 用一条经验中的奖励和下一观察估计值，构造当前所选动作应该靠近的目标。

```text
非终止：target = reward + 折扣因子 × 目标网络的最大下一 Q 值
真正终止：target = reward
```

这里说明普通一步 DQN：下一 Q 值来自目标网络。计算 target 时关闭梯度，使本次损失的 `backward()` 只沿在线网络的 `selected_q` 一侧传播。Double DQN 的选择规则另见 [[概念/DoubleDQN与价值高估]]。

## 目标是当前的估计依据，不是标准答案

假设回放里奖励为 0.1，任务未终止，目标网络对下一观察给出的最大 Q 为 0.8，γ = 0.9：target = 0.1 + 0.9 × 0.8 = 0.82。

其中 0.1 是经历中收到的奖励，0.8 是模型对未知后续的估计。target 为 0.82，不代表真实后续回报一定为 0.82；它会受估计误差影响。这与 [[概念/Q-learning更新]] 使用的是同一条数值链，只是估值来源从表格变成网络。

若在线预测为 0.2，平方损失为 (0.2 - 0.82)² = 0.3844，损失对预测的梯度为 2 × (0.2 - 0.82) = -1.24。它再沿在线网络传播到参数，见 [[概念/自动求导与梯度]]。

为什么停掉目标一侧的梯度？本次更新要让预测朝暂定目标靠近。若两侧都求导，优化器也可能通过移动“对照数值”降低损失，就换成了另一种优化问题。即使目标网络没有交给在线优化器，也应明确关闭目标支路的求导，避免无用的图与梯度。

## 结束语义

- `terminated=True`：任务状态真正结束，没有未来价值；
- 只有 `truncated=True`：被任务之外的条件截断，保留最后观察的未来价值；任务自带的有限时长另见 [[概念/标准环境接口]]；
- 两者都会结束当前 episode，但不能因此使用相同的 target。

## 职责边界

- target 不是即时奖励的同义词，非终止时还包含折扣后的未来估计；
- 最大下一 Q 值用于构造学习目标，不等于环境下一步真的执行该动作；
- target 不需要梯度，目标网络也不在在线优化器的这次更新中改变；
- 本节点聚焦目标构造；完整连接见 [[概念/DQN训练流程]]。
