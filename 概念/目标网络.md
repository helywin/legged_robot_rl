# 目标网络

目标网络是在线网络的一份延迟更新副本。在这里的普通 DQN 中，优化器更新在线网络；目标网络估计下一观察的未来 Q 值，再按约定同步。它来自过去的在线网络，不是一个知道正确答案的专家。

```text
在线网络：当前预测 → 接收误差 → 每次更新
目标网络：未来估计 → 暂时固定 → 定期同步
```

## 为什么需要它

如果同一组正在更新的参数同时决定当前预测和训练目标，参数变化时两边都会变化。暂时固定目标网络可以减慢这种相互追逐。对同一条固定经验、固定折扣、确定性的目标网络前向，普通 DQN 在两次同步之间可以得到相同 target。

## 固定网络，不等于每条经验的目标都一样

假设固定目标网络对某个下一观察输出 [2, 3]，折扣 0.9：

| 本次条件 | target |
| --- | --- |
| 奖励 0.5，尚未终止 | 0.5 + 0.9 × 3 = 3.2 |
| 奖励改为 1，尚未终止 | 1 + 0.9 × 3 = 3.7 |
| 同步后最大下一 Q 变成 4，奖励仍为 0.5 | 0.5 + 0.9 × 4 = 4.1 |

所以换了经验、奖励或下一观察，目标仍会变。[[概念/DoubleDQN与价值高估]] 还用在线网络选择下一动作，即使目标网络固定，选择变化也可能使 target 变化。若网络含随机层或会更新统计的层，还需核对它们的模式。

## 两份副本怎样保持独立

`target = online` 只是让两个名字指向同一个对象，并没有创建参数副本。需要独立的模型与参数存储，再按计划复制数值。在线反向和优化器更新不应把目标网络一起训练。

整份复制称为硬同步；也可以逐渐混合新旧数值，例如每次保留旧目标参数的 90%，加入在线参数的 10%。一个目标参数为 2、在线参数为 5 时，混合后为 0.9 × 2 + 0.1 × 5 = 2.3。这是另一种同步规则，不应与“每隔若干步整份复制”混为一谈。

## 职责边界

- 两份网络结构相同，但参数更新时机不同；
- 训练误差只直接更新在线网络；
- 同步是复制参数，不是利用一条新经验学习；
- `terminated=True` 时目标只使用奖励，不需要未来 Q 值；
- 目标网络不替代经验回放、探索或独立评估。
