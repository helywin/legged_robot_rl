# 目标网络

目标网络是在线网络的一份暂时固定参数副本。在线网络每次训练都会更新；目标网络只负责为非终止经验估计下一观察的未来 Q 值，并按固定间隔从在线网络同步参数。

```text
在线网络：当前预测 → 接收误差 → 每次更新
目标网络：未来估计 → 暂时固定 → 定期同步
```

## 为什么需要它

如果同一组正在更新的参数同时决定当前预测和训练目标，参数变化时两边都会变化。目标网络让目标在若干次更新内保持不变，减少“追赶不断移动的答案”的问题。

## 职责边界

- 两份网络结构相同，但参数更新时机不同；
- 训练误差只直接更新在线网络；
- 同步是复制参数，不是利用一条新经验学习；
- `terminated=True` 时目标只使用奖励，不需要未来 Q 值；
- 目标网络不替代经验回放、探索或独立评估。
