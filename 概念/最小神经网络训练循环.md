# 最小神经网络训练循环

训练循环把一次“清梯度、预测、计算损失、反向计算、更新参数”重复多次。每一步都继续使用上一步更新后的同一个模型。

```text
重复若干步：
    清空旧梯度
    当前模型完成预测
    计算当前损失
    backward() 计算梯度
    step() 更新模型参数
```

记录每一步损失可以观察学习是否朝预期方向发展，但损失下降只说明当前训练数据被拟合得更好。

每轮 `loss` 和计算图都会重新建立；它们通过 `backward()` 产生梯度，再由优化器把影响写入长期保留的模型参数。下一轮不是复用旧 `loss`，而是使用新参数产生新的预测与损失。

## 哪些对象留下，哪些对象重算

| 对象 | 普通连续训练中的处理 | 原因 |
| --- | --- | --- |
| 模型参数 | 跨轮保留并更新 | 保存学到的估计或决策方式 |
| 优化器与其历史状态 | 跨轮保留 | 继续沿用更新历史 |
| 当前输入与目标 | 按本次数据构造 | 本次可能抽到不同样本；DQN 目标也可能改变 |
| 预测、loss、反向计算图 | 每轮重新前向构造 | 必须反映当前参数 |
| `.grad` | 按设计清空或累积 | 只让预定数据决定本次更新 |

可以把参数理解成长期修改的草稿，loss 是按这一版草稿重新计算的检查结果。保留旧检查结果不会自动检查新草稿。

完整的一组手算数据从 [[概念/自动求导与梯度]] 的预测 1.1、损失 0.16 开始，接到 [[概念/优化器与参数更新]] 的新预测 1.5。这些数值说明机制，不代表本页新增了学习者训练证据。

## 职责边界

- 训练步不是环境的 `step()`，前者更新模型，后者推进环境；
- 在同一次连续训练中应保留已更新的模型，不能每步重新随机初始化；开始新的独立对照实验则另当别论；
- 反复拟合一条数据不代表模型能处理其他观察；
- 训练损失下降不等于冻结后的独立评估成功。
