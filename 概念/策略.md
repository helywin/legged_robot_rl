# 策略

策略回答一个问题：**得到当前观察后，下一步选什么动作？**

策略可以是人写的规则，也可以由 Q 表或神经网络参与构成。策略描述决策方式，不负责推进环境或发放奖励。

## 估值以后，还要规定怎样选动作

假设动作顺序为“左、右”，DQN 输出 Q 值 [1, 3]：

- 使用贪心规则：取最大值对应的动作，选右；
- 使用 ε-greedy：大部分时候选右，少部分时候随机抽一个动作，见 [[概念/探索与利用]]。

这里 [1, 3] 是两个价值估计，不是动作本身，也不是概率。**网络估值加上动作选择规则，才说明这次怎样决策。**

概率策略则可以明确给出“左 25%，右 75%”，再按这个分布抽取动作。同一观察下，不同次抽样可以得到不同动作。PPO 后续会学习这种概率怎样调整；现在只需区分“给动作估值”和“给动作分配概率”。

## 参数没变，动作为什么仍会变化

把策略想成一条规则：“偏左就向右，偏右就向左。”小车位置改变时，这条规则没有变，输出却会改变。这属于使用已有策略。

若训练后，把相同观察下“向右”的概率由 75% 调到 80%，才是策略本身发生了变化。冻结网络不等于冻结环境，也不等于始终输出同一个动作。
