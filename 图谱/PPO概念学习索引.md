# PPO 概念学习索引

PPO 从与环境交互的经历中学习动作策略。本索引把已经讨论的概念按依赖关系整理，便于暂停课程后查阅。各页先说明职责和因果，再给必要公式；公式用于查阅，不要求手算或做题。

课程停留在 [[课程/201-feedback-across-actions]] 的概念阶段，保持 learning。整理资料不代表已经掌握或完成实作；PPO 从 200 起，Go2 从 500 起，DQN 仍暂停。

## 先看整个过程

```text
Actor 根据观察产生分布并选择动作
    ↓
环境执行，返回下一观察与奖励
    ↓
记录连续经历及旧概率、旧价值
    ↓
真实奖励与价值预测组成收益依据
    ↓
减去价值基准，整理优势
    ↓
Actor 用优势改善选择，Critic 用回报目标改善预测
    ↓
有限轮更新后，用新策略继续收集经历
```

PPO-Clip 的裁剪作用在 Actor 更新的策略目标上。GAE 是一种优势估计方法，Actor-Critic 是职责划分；三者相关，但不是同一个概念。

## 统一符号，避免同字母表示两件事

| 符号 | 本组页面的含义 |
| --- | --- |
| $s_t,a_t,r_t,s_{t+1}$ | 动作前观察、本次动作、执行后奖励、下一观察 |
| $G_t$ | 从当前时刻开始的折扣回报 |
| $V^\pi,Q^\pi,A^\pi$ | 当前策略下的状态价值、动作价值与真实优势 |
| $V_{\mathrm{old}}$ | 更新前保存的价值预测，不代表必须有旧 Critic 网络 |
| $\delta_t$ | 单步时序差分误差 |
| $\hat A_t,\hat R_t$ | 估计优势、供 Critic 拟合的回报目标 |
| $\rho_t$ | 当前概率除以旧概率，和奖励 $r_t$ 分开 |
| $\gamma,\lambda,\epsilon$ | 回报折扣、GAE 组合参数、PPO 裁剪宽度 |

课程 200 的概率比沿用了论文常见的 $r$；本组概念页统一改用 $\rho$，含义相同。不同资料可能把本次转移奖励写作 $r_{t+1}$，应按动作与奖励的对应关系阅读。

## 常见混淆直接查

| 疑问 | 关键区别 |
| --- | --- |
| 没结束就不能学？ | 已有奖励可用；只有未见尾部需要预测 |
| Critic 只是自己相信自己？ | 目标包含实际奖励；新经历能提供纠正依据 |
| 正奖励一定增加动作概率？ | 需与原预期比较，还受裁剪及整批参数更新影响 |
| GAE 是新的网络？ | 它是处理奖励和价值预测的计算方法 |
| λ 为 0 就短视？ | 仍有下一状态价值；不能等同于 γ 为 0 |
| 裁剪把概率锁死？ | 它限制策略目标的部分优化收益，不是硬性概率约束 |
| 优势拿来训练 Critic？ | Critic 拟合回报目标，优势要先加回旧价值 |
| 算完 loss 就学了？ | 还需梯度与参数更新，下次前向才使用新参数 |
