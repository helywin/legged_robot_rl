# 强化学习概念图谱

> [!info] 两种索引各有用途
> `课程/001...` 是学习时间线，回答“我学到第几课”；本页和 `概念/` 是知识关系图，回答“这个概念和哪些概念有关”。

## 核心闭环

- [[概念/强化学习闭环]]：整张图的中心；
- [[概念/观察与动作]]：策略的输入和输出；
- [[概念/环境奖励与回合]]：执行动作并产生反馈；
- [[概念/策略]]：根据观察决定动作。

## 表格 Q-learning

- [[概念/Q表与Q值]]：保存每个“观察—动作”的估计分数；
- [[概念/探索与利用]]：在尝试新动作和选择当前最好动作之间取舍；
- [[概念/Q-learning更新]]：用一条经验修改一个 Q 值；
- [[概念/Q表完整训练流程与公式]]：用 PlantUML 总图、单格更新公式和冻结评估串起完整训练；
- [[概念/训练与评估]]：训练允许探索和更新，评估关闭二者。

## 环境接口与算法迁移

- [[概念/标准环境接口]]：用 `reset()` 和 `step()` 把不同任务接到同一训练循环；
- `terminated` 表示任务状态真正结束，`truncated` 表示被外部上限叫停。

## Q 表放不下以后

- [[概念/DQN与神经网络估值]]：网络接收观察，输出每个离散动作的 Q 值估计；
- [[概念/神经网络参数与预测]]：多个观察共享参数，预测阶段输出每个动作的 Q 值；
- [[概念/Python函数模型]]：先用普通函数理解输入、参数、局部计算和返回值；
- [[概念/Python类与对象]]：让模型对象在 `self` 中保存参数并重复预测；
- [[概念/PyTorch张量]]：把观察和参数放进 PyTorch 可统一计算的数据容器；
- [[概念/PyTorch模块与参数]]：用 `nn.Module` 登记参数，并在 `forward()` 中描述预测；
- [[概念/自动求导与梯度]]：从损失反向计算每个参数的变化方向，但暂不更新参数；
- [[概念/优化器与参数更新]]：读取参数梯度，按照学习率真正完成一次参数修改；
- [[概念/梯度累积与清零]]：解释 `backward()` 为什么累加梯度，以及新一轮更新前何时清空；
- [[概念/最小神经网络训练循环]]：把清梯度、预测、损失、反传和更新重复成连续学习过程；
- [[概念/线性层与多动作Q值]]：用一个 PyTorch 线性层把多项观察映射成顺序固定的多个动作 Q 值；
- [[概念/所选动作Q值与索引]]：按经验中的实际动作编号选择一个 Q 值，并让损失只连接到该输出；
- [[概念/批量张量与逐行动作索引]]：把多条经验堆成批量，并为每一行选择各自实际执行的动作列；
- [[概念/批量损失与梯度平均]]：先保留每条经验的损失，再取平均让整批共同贡献一次参数更新；
- [[概念/终止掩码与批量DQN目标]]：用逐行 1/0 开关让未终止经验保留未来值、终止经验只用奖励；
- [[概念/DQN目标Q值]]：用奖励、目标网络的最大下一 Q 值和终止语义构造无梯度 target；
- [[概念/预测误差与参数更新]]：比较所选动作的预测与目标，再让共享参数向减小误差的方向移动；
- [[概念/经验回放]]：保存并随机重用新旧经验，避免更新只追随最近的连续数据；
- [[概念/回放样本的字段批量化]]：保持行对齐，把抽出的经验对象按字段变成正确 shape 和 dtype 的张量；
- [[概念/目标网络]]：用暂时固定的参数计算未来 Q 值，再定期从在线网络同步；
- [[概念/DQN训练流程]]：把经验回放、在线预测、目标计算、误差和更新串成一次训练步骤；
- [[概念/DQN完整训练流程与公式]]：用 PlantUML 总图、两条更新支路和公式串起环境采集、在线学习与目标同步；
- [[概念/DQN小型基准]]：用 CartPole 隔离验证真实 DQN 训练和冻结评估闭环；
- [[概念/游戏强化学习路线]]：从小型离散动作任务走向 Chromium B.S.U.；
- [[概念/四足机器人强化学习路线]]：从共同基础走向 PPO、Isaac Lab 和 Go2。
