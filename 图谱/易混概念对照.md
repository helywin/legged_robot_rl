# 易混概念对照

本页按“哪里容易混淆”连接现有概念，可从正在困惑的一行进入，不必从头读完。课程顺序仍由 [[学习主页]] 和 [[PPO及感知四足课程路线]] 决定；补充知识不自动改变课程完成状态。

## 交互中的数字分别指什么

| 容易混淆的两件事 | 用一个例子分开 | 详细解释 |
| --- | --- | --- |
| 交互与学习 | 小车移动了一步，权重可能完全没变 | [[概念/强化学习闭环]] |
| 状态与观察 | 同在中心，一个向左滑、一个向右滑，只给位置就分不清 | [[概念/观察与动作]] |
| 累计分数与本步奖励 | 分数 100→120，本步增量是 20，不是 120 | [[概念/环境奖励与回合]] |
| 奖励与回报 | 奖励 [1,0,2]，γ=0.9 时从第一步算的回报为 2.62 | [[概念/奖励回报与折扣]] |
| Q 值与动作概率 | Q 为 [1,3] 不要求加起来为 1；还需要选动作规则 | [[概念/Q表与Q值]]、[[概念/策略]] |
| 折扣与学习率 | γ 改变怎么看未来，α 改变一次接受多少更新 | [[概念/Q-learning更新]] |
| 随机分支概率与非贪心概率 | 四动作、ε=0.2，唯一最好动作仍有 85% 概率被选中 | [[概念/探索与利用]] |
| 负奖励与任务终止 | 扣一条命得到负奖励，剩余生命仍允许继续 | [[概念/游戏事件与奖励终止]] |

## 网络更新时，究竟谁变了

| 容易混淆的两件事 | 关键区别 | 详细解释 |
| --- | --- | --- |
| 新变量名与新对象 | `b=a` 可以仍指向同一个模型 | [[概念/Python类与对象]] |
| 函数返回与输入不变 | 函数可以先修改列表，再返回同一个列表 | [[概念/Python函数模型]] |
| 数量相同与形状正确 | `(B,1)` 减 `(B,)` 可能变成 `(B,B)` | [[概念/PyTorch张量]] |
| 能求导与会被优化器更新 | 参数还要交给对应优化器，并正确连接损失 | [[概念/PyTorch模块与参数]] |
| 误差与梯度 | 预测偏低时，负输入可能要求权重减小 | [[概念/预测误差与参数更新]] |
| backward 与 step | 前者写入 `.grad`，后者读取梯度更新参数 | [[概念/自动求导与梯度]]、[[概念/优化器与参数更新]] |
| 清梯度与重置模型 | `zero_grad()` 不会把学到的权重恢复初值 | [[概念/梯度累积与清零]] |
| loss 的寿命与参数的寿命 | 每轮重建 loss，模型参数和优化器状态跨轮保留 | [[概念/最小神经网络训练循环]] |
| 平均误差与平均平方损失 | [1,-1] 的误差平均为 0，平方后平均为 1 | [[概念/批量损失与梯度平均]] |
| 某样本变好与所有预测变好 | 共享权重也会影响没参加本轮训练的观察 | [[概念/共享参数与预测联动]] |
| Huber 与奖励裁剪 | Huber 改损失斜率，不直接裁剪环境奖励 | [[概念/平方损失与Huber损失]] |

## DQN 数据为什么容易接错

| 容易混淆的两件事 | 关键区别 | 详细解释 |
| --- | --- | --- |
| 当时实际动作与现在最优动作 | 经验执行了动作 2，就训练那一列，不能临时改成 argmax | [[概念/所选动作Q值与索引]] |
| 行对齐与形状正确 | 单独排序 actions，形状没变，经历却被拼错 | [[概念/回放样本的字段批量化]] |
| 目标网络与正确答案 | 目标网络是延迟副本，其估计仍可能错误 | [[概念/目标网络]]、[[概念/DQN目标Q值]] |
| 真正终止与外部截断 | 同样停止交互，是否接未来价值可能不同 | [[概念/标准环境接口]]、[[概念/终止掩码与批量DQN目标]] |
| 最后观察与重置首帧 | 重置到中心不能冒充上一动作的真实后果 | [[概念/环境交互到经验记录]] |
| 观察历史与经验回放 | 前者给当前决策提供时间线索，后者重用旧经历训练 | [[概念/经验回放]] |
| 最近槽位与同一个物体 | 两帧槽 0 可能装不同子弹，不能直接相减算速度 | [[概念/单帧观察与运动信息]] |
| 环境步与网络更新 | 预填充四步后才允许第一次更新，两种计数不同 | [[概念/回放预填充与训练起点]]、[[概念/DQN训练的三种计数]] |
| 决策时间与物理小步 | 保持四帧改变反应间隔，也改变折扣的时间含义 | [[概念/动作保持与观察时间对齐]] |
| 训练损失与控制效果 | 拟合了本批目标，不代表在独立回合更稳定 | [[概念/训练与评估]] |

## 三条可以慢慢读的连接

**想把一次更新真正串起来：**

[[概念/奖励回报与折扣]] → [[概念/Q-learning更新]] → [[概念/DQN目标Q值]] → [[概念/自动求导与梯度]] → [[概念/优化器与参数更新]] → [[概念/最小神经网络训练循环]]。

其中 Q-learning 与 DQN 目标共用“奖励 0.1、下一估计 0.8、γ=0.9”的数据；求导与优化器共用“x=2、w=0.5、b=0.1、目标1.5”的数据。每条链内部沿用同一组数字，跨到另一组时会明确重新给定条件。

**想理解 DQN 的不同改进：**

先看 [[概念/DQN训练流程]] 定位目标、网络、抽样、探索分别在哪里，再进入 [[图谱/DQN改进方法自学路线]]。不要一开始把所有改进一起打开；各页给出的作用机制不等于当前任务已验证的收益。

**想接到 PPO 与四足：**

[[概念/策略]] → [[概念/值函数与优势]] → [[概念/观察与动作]] → [[概念/策略动作到关节控制]]。

左动作奖励 2、优势却可以为 -1；策略动作 0.4，也可以先变成目标角度 0.9 rad，再由控制器算出力矩。这两组例子分别说明“按什么评价动作”和“动作怎样作用于身体”。正式实作依旧按既定课程逐步进行。
